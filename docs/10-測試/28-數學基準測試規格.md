# 28｜數學基準測試規格

> AXIOM v2.1 整合基線｜文件 ID AX-28｜狀態：設計基線（未實作）｜2026-10-19

## 1. 文件定位與決策摘要

盲測矩陣至少交叉：5/20/100/1000 點、狹域/廣域、float64/高精度、無噪/異質噪/離群值、規則/不規則採樣、同族/跨族公式；評估置信區間與跨 seed 變異。

**設計原則**：每個規範都要能轉換成可測試的行為、可追溯的證據或明確的工程決策；凡屬目標數字均非已實測結果。

## 2. 章節專屬規格

### 測試矩陣

樣本數 5/20/100/1000/10000；觀測精度與計算精度分離；採樣域窄/寬/不規則；雜訊 Gaussian/厚尾/異方差/相關；缺值、離群、截斷、量化；公式家族單一/組合/分段/動態/離散/隨機。

### 對抗案例

sin(x) 與 Taylor 近似、aliasing、極點附近有理式、過擬合高次多項式、近共線參數、混沌系統、分布漂移、純隨機數據、跨域失效、反例誘導。

### 指標與判定

結構等價、參數誤差、內插/外插、導數、數值穩定、候選可區分、拒答校準、時間與成本；保留盲測且按家族分層報告。

### 禁止事項

不能用同一生成公式族的不同參數作為「未知結構」測試；不能以更高浮點精度取代測量精度；不能只報告最佳成功案例。

## 3. 能力分解與詳細規格

### 3.1 基準資料集設計

建立簡單解析式、複合式、近似不可辨、噪聲／缺值、奇異點／病態、離散遞迴、動態系統、純隨機無規律、變點及跨域外插等家族。

**強制規則／例外處理**：生成公式、參數與測試答案隔離；新演算法不得讀取 hidden ground truth。

### 3.2 測試切分

訓練／開發／盲測依公式結構、參數區間、資料生成器版本與案例來源隔離；時間序列採前推驗證。

**強制規則／例外處理**：禁止同公式僅換係數後跨越家族盲測界線。

### 3.3 評估指標

結構等價率、候選 Top-k、樣本外 RMSE/MAE、外插風險、覆蓋率、錯誤自信率、拒答品質、計算成本、重現率與記憶增益。

**強制規則／例外處理**：精度測試必須區分測量精度與算術精度；高精度數值吻合不構成一般證明。

### 3.4 品質閘門

單元、屬性、變形、契約、整合、端到端、效能、資安、可存取性、回歸、盲測；形式化證明須檢查完整假設。

**強制規則／例外處理**：嚴重數學錯誤、資料洩漏或證據等級誤標視為阻擋發布。

## 4. 關鍵技術決策與邊界條件

1. 評估必須包含純隨機資料，測量系統能否拒絕虛假規律。

2. 相似公式對抗案例：sin(x) 與截斷泰勒在窄域不可分，擴大觀測域後再測辨識能力。

3. 對時間序列使用 walk-forward，對非 IID 數據不可用一般隨機切分。

4. 基準報告需同時提供平均、分位數、最差家族與信賴區間，不可只呈現最佳 seed。

## 6. 失敗情境與降級策略

| 失敗或風險 | 系統反應 | 留存證據 |
|---|---|---|
| 輸入不符合「數學基準測試規格」要求 | 拒絕執行並提供可修正的欄位錯誤 | 輸入版本、驗證規則、錯誤代碼 |
| 依賴服務中斷或超時 | 有限次重試；超出預算即終止並保存 checkpoint | 服務版本、耗時、重試紀錄 |
| 結果彼此衝突或證據不足 | 保留候選及歧義，不提升證據等級 | 候選集合、反例、驗證集 |
| 資源配額超出 | 中止重運算，保留已完成的可信部分結果 | CPU/GPU 秒、記憶體峰值、任務狀態 |

## 7. 可執行驗收案例

**AC-28-01 正常路徑**：給定完整合法的輸入、固定資料版本與計算預算，執行「數學基準測試規格」流程，必須產出可追溯的結果與完成狀態。

**AC-28-02 異常路徑**：故意提供缺欄、錯誤型別、超時或不合法狀態，必須得到明確診斷且不得產生已驗證的假結果。

**AC-28-03 重現性**：在固定輸入、版本、隨機種子與執行環境下重跑，輸出應符合預先定義的決定性或容差標準。

**AC-28-04 權限與審核**：未授權角色不得讀取或發布研究資料；審核者能查詢完整證據鏈。
