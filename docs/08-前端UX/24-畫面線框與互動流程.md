## 操作流程

```mermaid
flowchart LR
 A[選資料]-->B[品質報告]
 B-->C[選研究預算]
 C-->D[啟動研究]
 D-->E[即時候選與曲線]
 E-->F[選公式比較]
 F-->G[推演/證明/反例]
 G-->H[審核並發布]
```

## 效能體驗

首屏顯示骨架與任務摘要；長任務使用 SSE 推送增量候選；圖表只重繪變動圖層；前端虛擬列表顯示大量實驗；公式排版快取。

## 驗收與交付準則
- 文件內所有決策均有負責角色、驗證方法及可追溯的需求編號。
- 未完成事項不得標示為已實作；未經獨立驗證的數學主張不得標示為已證明。
- 重大設計變更應同步更新索引、架構決策與相關測試計畫。
