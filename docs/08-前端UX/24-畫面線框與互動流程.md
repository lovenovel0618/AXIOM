# 24｜畫面線框與互動流程

> AXIOM v2.1 整合基線｜文件 ID AX-24｜狀態：設計基線（未實作）｜2026-10-19

## 1. 文件定位與決策摘要

工作台三欄：左資料／條件，中圖表／公式疊加，右候選／證據；下方進度與日誌。選候選時同步更新圖線、殘差、參數表與推導樹；對比模式最多四條候選並排。

**設計原則**：每個規範都要能轉換成可測試的行為、可追溯的證據或明確的工程決策；凡屬目標數字均非已實測結果。

## 2. 章節專屬規格

### 研究工作台線框

```text
┌──────────────── AXIOM Research Studio ────────────────┐
│ 專案 / 資料版本 / 研究狀態 / 預算 / 匯出             │
├──────────────┬────────────────────────┬──────────────┤
│ 資料與假說樹 │ 散點 + 候選曲線 + 區間  │ 候選公式排名 │
│ 特徵與篩選   │ 縮放/刷選/圖層切換      │ 參數與證據   │
├──────────────┴────────────────────────┴──────────────┤
│ 殘差 | 精度壓測 | 推導步驟 | 反例 | 研究時間軸       │
└───────────────────────────────────────────────────────┘
```

### 操作流程

```mermaid
flowchart LR
 A[選資料]-->B[品質報告]
```

### 效能體驗

首屏顯示骨架與任務摘要；長任務使用 SSE 推送增量候選；圖表只重繪變動圖層；前端虛擬列表顯示大量實驗；公式排版快取。

## 3. 能力分解與詳細規格

### 3.1 資訊架構

首頁儀表板、資料集、研究工作台、公式探索器、公式片段庫、推導證明工作台、理論演化圖、基準測試、AI 模型中心、系統管理。

**強制規則／例外處理**：每個主要頁面均有空狀態、載入狀態、失敗狀態與權限不足狀態。

### 3.2 研究工作台

左側資料與研究設定；中央散點／函數／殘差疊圖；右側候選公式、證據與假說；底部執行時間線與工作日誌。

**強制規則／例外處理**：可切換線性／對數軸，顯示採樣域與外插域邊界，不能用平滑線掩蓋離散觀測。

### 3.3 公式呈現

KaTeX 讀取 LaTeX；MathLive 編輯；Plotly 支援縮放、hover、圖層；大型資料採抽樣與視窗化；公式顯示和計算結構保持對應。

**強制規則／例外處理**：每條公式可展開參數、假設、推導鏈、誤差與適用域；複製 LaTeX 與匯出報告。

### 3.4 視覺可信度

觀測點、擬合線、預測區間、外插區間、驗證集及反例使用明確不同視覺語意；色彩不能作為唯一辨識依據。

**強制規則／例外處理**：高風險狀態要有文字標籤；支援鍵盤、縮放、螢幕閱讀器及手機閱讀。

## 4. 關鍵技術決策與邊界條件

1. 研究頁應能鎖定觀測域、標出訓練/驗證/測試分界，外插區域以不同底色及警告呈現。

2. 選擇公式片段時可在公式 AST 樹與圖形中的對應成分之間雙向高亮。

3. 候選對比視圖至少提供公式、參數、RMSE、複雜度、穩定性、適用域、反例與成本。

4. 推導工作台逐步顯示前提、變換規則、數學結果與 proof status，不將 AI 說明視為證明。

## 6. 失敗情境與降級策略

| 失敗或風險 | 系統反應 | 留存證據 |
|---|---|---|
| 輸入不符合「畫面線框與互動流程」要求 | 拒絕執行並提供可修正的欄位錯誤 | 輸入版本、驗證規則、錯誤代碼 |
| 依賴服務中斷或超時 | 有限次重試；超出預算即終止並保存 checkpoint | 服務版本、耗時、重試紀錄 |
| 結果彼此衝突或證據不足 | 保留候選及歧義，不提升證據等級 | 候選集合、反例、驗證集 |
| 資源配額超出 | 中止重運算，保留已完成的可信部分結果 | CPU/GPU 秒、記憶體峰值、任務狀態 |

## 7. 可執行驗收案例

**AC-24-01 正常路徑**：給定完整合法的輸入、固定資料版本與計算預算，執行「畫面線框與互動流程」流程，必須產出可追溯的結果與完成狀態。

**AC-24-02 異常路徑**：故意提供缺欄、錯誤型別、超時或不合法狀態，必須得到明確診斷且不得產生已驗證的假結果。

**AC-24-03 重現性**：在固定輸入、版本、隨機種子與執行環境下重跑，輸出應符合預先定義的決定性或容差標準。

**AC-24-04 權限與審核**：未授權角色不得讀取或發布研究資料；審核者能查詢完整證據鏈。

## 8. 實作任務分解與交付物

| 順序 | 工作項 | 完成定義 |
|---|---|---|
| 1 | 規格與輸入輸出契約 | 完成 schema、狀態與錯誤定義，審查通過 |
| 2 | 核心流程與依賴整合 | 完成可重現的端到端最小流程 |
| 3 | 邊界與反例測試 | 正常、異常、資源限制及證據不足皆有測試 |
| 4 | 視覺化與運維可見性 | 使用者可理解結果、限制、進度與失敗原因 |
| 5 | 發布審核 | 有版本、驗收紀錄、回滾方案及已知限制 |
