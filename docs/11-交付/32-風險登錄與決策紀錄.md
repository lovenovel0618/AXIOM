# 32｜風險登錄與決策紀錄

> AXIOM v2.3 設計規格｜文件 ID AX-32｜狀態：待實作、待驗收｜2026-10-19

## 文件定位與決策摘要

高風險：有限樣本不可識別、搜尋爆炸、LLM 幻覺、資料洩漏、盲測污染、符號證明超時、GPU 供應、授權相容；每項建立 trigger、mitigation、fallback、owner。

## 章節專屬規格

### 主要風險

| ID | 風險 | 緩解 |
|---|---|---|
| RISK-01 | 過度擬合被誤判為發現 | 盲測、拒答、外插測試 |
| RISK-02 | 記憶負遷移 | no-memory 對照、降權 |
| RISK-03 | LLM 幻覺推導 | AST、獨立驗證、證明核心 |
| RISK-04 | 計算成本失控 | 預算、早停、佇列隔離 |
| RISK-05 | 測試集污染 | 家族隔離與權限隔離 |
| RISK-06 | 敏感資料外傳 | 本地路由、資料分級 |
| RISK-07 | 公式 DSL 擴充破壞相容 | schema 版本、遷移測試 |
| RISK-08 | UI 大數據卡頓 | 降採樣、增量繪圖 |

### ADR 模板

每項決策記錄 ID、背景、選項、決策、理由、影響、回退條件、日期與審核人；先行決策：ADR-001 Django 模組化單體；ADR-002 PostgreSQL+pgvector；ADR-003 公式 AST/DSL；ADR-004 數學驗證與 AI 分離；ADR-005 任務佇列隔離；ADR-006 以 Docker Compose 統一環境：開發於 macOS、架設於 Windows 11 + WSL2（背景：需在兩種平台上可重現地架設同一套服務，且開發與架設不得分歧；選項：各平台宿主直裝／單一 Compose 定義跨平台／雲端開發環境；決策：採單一 Compose 定義，macOS 供開發與基準、Windows WSL2 供實際架設，差異僅以覆寫檔表達；理由：環境可重建、兩平台同構、避免污染宿主、基準數據可互相比較；影響：需維護多架構映像、健康檢查，以及 WSL2 的路徑、換行與資源上限規範；回退條件：Mac 資源不足時改以 WSL2 為主要環境，或需 GPU 直通時改採獨立 Ubuntu 主機）。

### 定期治理

每個里程碑重評風險；高風險項目設具體負責人、預警指標與回退預案。
