## ADR 模板

每項決策記錄 ID、背景、選項、決策、理由、影響、回退條件、日期與審核人；先行決策：ADR-001 Django 模組化單體；ADR-002 PostgreSQL+pgvector；ADR-003 公式 AST/DSL；ADR-004 數學驗證與 AI 分離；ADR-005 任務佇列隔離；ADR-006 本地開發以 Docker Compose 統一環境（背景：需在 macOS 可重現地架設全套服務；選項：宿主直裝／Compose／雲端開發環境；決策：Compose，Mac 本地 CPU 執行、Ollama 以宿主原生服務路由；理由：環境可重建、與正式部署同構、避免污染宿主；影響：需維護映像與健康檢查；回退條件：Mac 資源不足或需 GPU 直通時改用宿主直裝或 Ubuntu 主機）。

## 定期治理

每個里程碑重評風險；高風險項目設具體負責人、預警指標與回退預案。

## 驗收與交付準則
- 文件內所有決策均有負責角色、驗證方法及可追溯的需求編號。
- 未完成事項不得標示為已實作；未經獨立驗證的數學主張不得標示為已證明。
- 重大設計變更應同步更新索引、架構決策與相關測試計畫。
