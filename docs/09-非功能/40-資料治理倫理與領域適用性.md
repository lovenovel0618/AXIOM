# 40｜資料治理倫理與領域適用性

> AXIOM v2.3 設計規格｜文件 ID AX-40｜狀態：待實作、待驗收｜2026-10-19

## 文件定位與決策摘要

跨領域資料須定義使用目的、合法來源、保留與刪除政策；社會與行為研究要報告群體代表性、測量偏差與混雜；因果主張需要明確識別設計而非單靠曲線。

## 章節專屬規格

### 領域適用

社會與行為資料需處理群體差異、選樣偏差、隱私與混雜；醫療與高風險決策需人工專家與額外法規審核；金融預測需呈現漂移與風險，不得以高擬合率暗示獲利保證。

### 資料治理

資料授權、同意與目的限制；個資去識別與存取審計；跨專案記憶共享需明確授權；對外模型路由依敏感度與法規要求控管。

### 科學誠信

保留負結果與反例；禁止只報告成功候選；跨群組檢查表現差異；對每個結論呈現替代假說與適用邊界。
