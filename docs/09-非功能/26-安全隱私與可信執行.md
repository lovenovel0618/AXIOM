# 26｜安全隱私與可信執行

> AXIOM v2.7 設計規格｜文件 ID AX-26｜狀態：待實作、待驗收｜2026-10-20

## 威脅與信任邊界

資料、上傳檔、公式、LLM 輸出、插件與 checkpoint 均不可信。需涵蓋惡意檔案、AST／prompt injection、資源耗盡、越權、盲測污染、秘密外洩及供應鏈。LLM 不得操作資料庫或宿主；插件只寫受限暫存。AST／求值在無特權 sandbox 執行，禁止 eval/exec、不可信 pickle 及宿主 Docker socket。

sandbox 使用非 root、唯讀根目錄、無網路、cap_drop=ALL、CPU/memory/pids/time 上限；輸入唯讀、輸出為獨立可寫 quota 目錄。可信 supervisor 驗證輸出大小、型別、hash 與 generation 後才可提交 DB。符號工具或 checker 不因是第三方套件就取得更多權限。

## 認證與角色

MVP 瀏覽器採同源服務端 session；cookie 為 HttpOnly、Secure、SameSite=Lax，所有變更須 CSRF header。session 登出／角色撤銷後失效，預設閒置 30 分鐘、最長 12 小時。這些為可調安全基線，不宣稱已測。服務帳號用短效 bearer token（預設 1 小時），綁 tenant、audience 與 scopes；只保存 token hash，支援撤銷。瀏覽器不得把服務 token 放 localStorage。

| 操作 | viewer | researcher | reviewer | admin | service |
|---|---|---|---|---|---|
| 讀研究／候選／證據 | 授權範圍 | 授權範圍 | 授權範圍 | 不自動取得資料讀權 | scopes 及任務範圍 |
| 建資料／研究／執行 | 否 | 是，需 editor ACL | 需另具 researcher | 需另具 researcher | 明確 write scope |
| 取消任務 | 否 | 自有／editor | 非自動 | 僅資源緊急停機，必須審計 | 自有任務 scope |
| 核准／撤銷證據 | 否 | 否 | 是，但不得是來源作者／run 發起者 | 需另具 reviewer 且仍不得自核 | 否 |
| 配額／角色／模型組態 | 否 | 否 | 否 | 是，資料讀權另授 | 限定 admin scope |
| 外部資料分享／更改敏感度 | 否 | 提申請 | 覆核 | 執行已批准政策 | 否 |

每個資源含 tenant_id、owner、ACL；跨租戶與無讀權 UUID 一律 404，列表與 cursor 同樣過濾。viewer 不等於公網公開；MVP 不提供匿名分享連結。SSE 與下載 URL 必須持續受限，撤銷後禁止開新連線並中止既有串流；signed URL 有 15 分鐘上限，若有即刻撤銷要求改由授權 proxy，不發不可撤銷外鏈。

## 資料等級與外送政策

| 等級 | 本地 Ollama／規則 | 外部 LLM | 跨專案記憶／訓練 |
|---|---|---|---|
| PUBLIC | 可，仍需授權來源 | 僅 D-04 審核供應商後，提交最小摘要 | 分別明確授權 |
| INTERNAL | 同租戶本地處理 | 預設禁止；逐研究例外須資料 owner＋reviewer 核准 | 預設禁止 |
| RESTRICTED | 受控本地隔離，模型服務不得保留原資料 | 禁止，不能自動回退到雲端 | 禁止，另案政策才可變更 |
| UNKNOWN | 先隔離與分類，禁止模型路由 | 禁止 | 禁止 |

外送檢查在 Gateway 實際發送前執行，不能僅依 UI 勾選；包含 prompt、特徵、候選公式及錯誤回報。模型失效只能在同等或更嚴格政策的本地路由間回退；無合法路由就停用 AI、使用規則搜尋或回 FEATURE_DISABLED。匿名化名稱不保證資料已失去敏感性。記錄 policy_version、批准者、payload hash、目的地及 token 成本，日誌不存原資料或秘密。

## 刪除、證據撤銷與衍生物傳播

以 lineage 計算影響範圍：原始檔→特徵→候選／驗證→記憶 embedding／快取→報告→訓練快照→模型版本。刪除與撤銷是不同操作；撤銷先在權威 DB 同交易新增記錄、禁止推薦／發布及寫 outbox，再異步清除索引／快取。所有推薦與報告下載都回查權威有效性，不能只信快取 TTL。

撤銷工作狀態為 REQUESTED／BLOCKED／PROPAGATING／COMPLETED／FAILED。保存每個受影響物件、動作、重試及錯誤；部分清理失敗不得顯示 COMPLETED。歷史報告保留允許的非敏感內容並醒目顯示撤銷／新證據；敏感內容刪除依政策不得只加標籤。已有外部匯出無法技術收回，記錄受影響匯出與允許的處理程序，不假稱已全部消除。

含撤銷／未授權資料的訓練快照移出可訓練清單；相關模型標 QUARANTINED 並停止服務，回退到無該 lineage 的有效模型，無有效模型則停用。重新訓練與重新驗收後才能解除，不宣稱刪一列就能從權重抹除資料。

備份保留受限且不供線上查詢；刪除 tombstone 清單獨立備份。還原後先重播刪除／撤銷清單再對外服務；備份到期清除、法律保留例外與資料年限由 D-05 決定，未決時不接收受此政策約束的真實敏感資料。

## 內部紀錄與串流授權

RunRecord／AttemptRecord、BudgetAccount與UsageReport只供有任務scope的可信服務，不透過公開OpenAPI。Heartbeat／計量入口驗證服務身分與attempt所屬，遲到計量可接受但不授予產物提交權。兩種stream及所有cursor重播均重新檢查當前ACL；冪等回應重播也須重新授權，不能以曾經成功當作永久讀權。

## 封存資料的逐資源讀取政策

Artifact.access_class必填PROJECT／SEALED_DETAIL／RELEASED_AGGREGATE，由可信服務依內容與lineage設定，客戶端不可自行降級。原始正式blind檔、final labels、逐點殘差、逐題分數、完整評估報告、final ValidationRun及其EvidenceBundle都受SEALED_DETAIL政策；一般自有資料原檔不因切分而自動變成正式未知blind，仍不得把final投影給Solver。

| 內容 | 一般viewer／researcher／admin | 隔離覆核者 | Evaluator服務 | Solver服務 |
|---|---|---|---|---|
| PROJECT | 依ACL | 依ACL | 任務scope | 僅任務授權的fit/development投影及開發產物 |
| SEALED_DETAIL | 拒絕，即使有研究reader或admin角色 | 需reviewer角色、獨立覆核條件、資源ACL及服務端核發sealed-review:read授權 | 需final:evaluate，綁tenant／submission／有效評估run | 拒絕 |
| RELEASED_AGGREGATE | 依ACL且發佈政策檢查通過 | 同左 | 需讀取scope | 拒絕進入搜尋、檢索及訓練 |

隔離覆核者須與來源作者／run發起者不同；授權由管理政策核發並審計，不接受請求body/header自稱隔離角色。Evaluator權限不能用於讀其他submission。任務scope不是整個研究的任意讀權，不能從已授權Candidate沿Artifact／DatasetVersion繞到final原檔。封存權限同時套用metadata、下載、ValidationRun、EvidenceBundle、PublishedArtifact、清單、快照、事件與冪等回放；無權讀完整資源回404，不回部分偽造的ValidationRun。快照／列表過濾無權引用，事件按當前身分過濾且維持原stream sequence，客戶端容許授權過濾造成序號間隙。

RELEASED_AGGREGATE是另建且不可變的報告Artifact：可信發佈服務在獨立核准交易中依版本化披露政策，驗證彙總樣本量及再識別風險、去除單題／逐點結果與私有種子，保存來源及批准紀錄後才可建立。樣本太少不能安全彙總時不提供可讀聚合報告。原SEALED_DETAIL不降級、不改內容或hash；退役亦不自動公開。已發布或匯出不豁免撤銷及敏感政策。Schema／OpenAPI只記規則與形狀，授權必須在服務端逐次執行。

| ID | 情境 | 預期 |
|---|---|---|
| AC-26-05 | reader／admin／Solver取final報告metadata、content、ValidationRun或bundle | 均404，不因研究ACL而放行；列表／SSE不洩漏受限內容 |
| AC-26-06 | 有隔離授權reviewer或綁定Evaluator讀final；改用其他submission | 前者依ACL可讀；跨提交拒絕，自我覆核仍禁止 |
| AC-26-07 | 一般reader讀已核准聚合報告，或Solver讀同報告 | 前者按ACL可讀；後者拒絕；原始詳細報告不降級 |

一般reader的Run仍可顯示控制狀態與自身允許的開發結果；若outcome_status或stop_reason透露受限final結論，對該身分回null，受限evidence／child引用不回傳。完整內部狀態不修改，授權投影及current_event_cursor在同一一致性讀點產生。ValidationFinished等含受限final引用的事件不投遞給Solver／一般reader；不能將隱藏指標寫入通用log、錯誤details、trace或通知。一般工作台不從被遮罩的null推斷零誤差或未執行。

## 永久責任歸屬、獨立審查與安全摘要

每個研究輸入、研究版本、執行根、人工候選／公式修改與發布來源，建立時同交易產生私有ResourceProvenance，資源(type,id,tenant)唯一；creator_actor_id是不可變actor身分，responsible_human_ids包含直接作者、人工代送者及來源責任人的閉包，服務帳號必須繼承啟動人的責任集合。RunRecord.provenance_id指向它，子任務沿root及source_provenance_ids繼承，不能由worker自填乾淨身分。循環／缺失／跨租戶來源一律阻擋核准，不能當成「無作者」。建立者、研究發起者與任何來源責任人不得核准自己的成果，即使改owner、移轉研究、改用管理員或服務帳號皆同。

帳號刪除保留不可逆actor tombstone與必要責任關係，不能重用actor ID；具體保留期限／法規由D-05決定，未核准前不提供清除責任鏈的刪除操作。撤銷現行grant不刪歷史作者；grant是目前授權，provenance是歷史事實，兩者分開。MVP研究共享以管理員受控ACL設定為限，未定義邀請／公開分享API就不在UI顯示可用。所有deny／審核／釋出均記持久audit，不能依賴24h冪等回應或7天SSE還原作者。

Review交易依固定順序鎖ResearchVersion→EvidenceBundle→政策版本，讀取完整責任閉包及目前grant，核對expected revision、ACTIVE來源、claim及policy後才提交；換owner／改grant與審核競態必須線性化。作者不得藉審核服務代理自己通過。隔離審核grant限制來源、用途及期限，service bearer不可呼叫人工APPROVE。

原始final claim／報告繼續SEALED_DETAIL。獨立摘要是另一份不可變RELEASED_AGGREGATE Artifact，從經核准的安全投影生成，不是換原檔access_class。釋出者必為獨立reviewer，D-05需核准可釋出欄位、最小群組與差分查詢／多次釋出規則，否則DISCLOSURE_POLICY_BLOCKED，不臆造安全k值。policy Artifact必須由管理端核准登錄，請求不能上傳一份自稱APPROVED的JSON冒充政策。合法ReleasedSummary的來源封存性由已核准的披露邊界處理：服務驗證已登錄的SummaryLineage及安全投影後，一般reader只需摘要本身ACL，不必取得原bundle讀權；這是唯一的受控釋出例外。任意衍生Artifact仍繼承封存限制，不能只自填RELEASED_AGGREGATE或release_checked降級。來源的撤銷／隔離仍沿私有lineage立即生效；Solver無此例外。私有SummaryLineage與摘要共同保存；發布policy不等於disclosure policy，核准研究不會自動解除封存。
