# 27｜可觀測性備份與故障復原

> AXIOM v2.5 設計規格｜文件 ID AX-27｜狀態：待實作、待驗收｜2026-10-20

## 觀測欄位與告警

每個請求／run／attempt 以 request_id、trace_id、tenant_id、research_version_id、run_id、generation 連接日誌與產物。指標至少含 API latency/error、queue age、attempt retry、租約回收、checkpoint 失敗、DB/物件容量、outbox lag、盲測存取拒絕、政策路由、CPU/GPU/token 用量及驗證 UNKNOWN／拒答。禁止以秘密或原始資料作 log 或 metric label。

錯誤率、queue age、容量、取消 grace 超時及 revoked cache 命中告警門檻由 D-06 凍結；校驗失敗、越權或真值洩漏一經發現立即停止受影響研究並產生事件，不等待平均門檻。

## 可還原的備份集

BackupSet 包含 backup_set_id、schema/DSL/app 版本、DB restore point/WAL 範圍、物件 version_id/checksum manifest、模型／組態清單、secret_key_version 引用、outbox 高水位、刪除／撤銷 ledger 高水位、建立時間及保管位置。金鑰內容不能與加密備份同放；需另有授權的金鑰復原方式。

MVP 以受控 maintenance window 建立一致集：停止接受新寫入、排空提交交易與 outbox、記錄高水位，取得 DB 一致性快照與全部被引用的物件版本清單，驗證物件可讀及 checksum，再解除 maintenance。不可只拷貝正在寫入的 DB 目錄。後續可用 PITR，但必須證明 DB restore point 引用的每個物件版本都保留。

暫定本地開發每天一次備份並保留 7 個完成集，僅是開發預設。正式 RPO/RTO、異地策略、保留與敏感資料期限屬 D-05／D-06，未定不宣稱具有正式災難復原保障。Redis 不作權威資料來源；任務與事件可從 DB 重建。

## 恢復 Runbook

| 順序 | 操作 | 檢查與失敗處理 |
|---|---|---|
| 1 | 隔離恢復環境，停 API 寫入、worker、beat、Gateway | 確認不會向外送資料或重複執行舊任務 |
| 2 | 選定完整 BackupSet、取得必要金鑰版本 | 缺 key 或 manifest 不完整則停止，不試空密碼 |
| 3 | 先還原所需物件／模型版本，再還原相配 DB 快照 | 驗證每個 DB artifact 引用可讀、size/hash 相符 |
| 4 | 檢查 schema/DSL/parser/app 相容並跑必要遷移 | 不相容先回相配映像，禁止跳過錯誤 |
| 5 | 重播備份後獨立保存的刪除／撤銷 ledger | 敏感內容與模型須先隔離，避免重新對外出現 |
| 6 | 清理過期租約、generation 遞增、重建 Redis/outbox 派送 | 舊 worker 與舊憑證不能提交；事件重送去重 |
| 7 | 重建快取／向量索引，只索引有效且有授權證據 | 舊索引不能先行提供推薦 |
| 8 | 執行小型研究與只讀檢查，開 API 讀流量再開 worker／寫入 | 驗證跨租戶、checksum、run 唯一與事件連續 |

復原驗收至少比對：所有引用物件 hash、DatasetVersion／EquationVersion 數、未完成任務清單、EvidenceBundle 有效性、刪除 tombstone、published 指向、模型狀態及 idempotency ledger。發現缺檔時標記不可用並保持受影響範圍關閉，不用新檔取代原證據。

## RPO／RTO 量測與回退

RPO=最後已確認寫入至可恢復寫入點的資料損失時間，另報實際遺失筆數；RTO=故障宣告至恢復驗收後可提供預定服務的時間。單純 DB 啟動不算服務恢復。演練保存故障時間、快照、命令／版本、檢查結果與覆核者。遷移不能逆轉時從相容 BackupSet 還原，不能只降映像。

| ID | 演練 | 預期 |
|---|---|---|
| AC-27-01 | DB 引用物件在備份中缺失 | 驗收失敗，保持寫入關閉，列明缺失物件 |
| AC-27-02 | 故障前已撤銷資料，還原較早快照 | 重播 ledger 後仍不可查詢／推薦／推論 |
| AC-27-03 | Redis 全毀、DB/outbox 完整 | 重建工作與串流，不重複發表或扣款 |
| AC-27-04 | 從凍結 BackupSet 跑 B-LINE | 來源 hash 不變、結果符合同容差，記錄真實 RPO/RTO |
