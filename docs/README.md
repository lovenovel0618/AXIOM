# AXIOM｜完整專案企劃與工程設計基線

> 整合版本 v2.1｜2026-10-19｜狀態：設計基線，尚未實作

AXIOM（Adaptive eXploration, Inference, and Objective Mathematics，公理探索）是一套跨領域數據驅動的公式發現、數學推演、證據驗證、長期記憶與自適應策略學習平台。本目錄是整合後的文件入口；涵蓋產品需求、工程契約、架構、畫面與驗收規格。目前儲存庫沒有可執行的產品程式或 Compose 定義，文件中的命令、SLO、工期與容量是設計與驗證計畫。

## 核心決策與閱讀邊界

- 後端採 Django／DRF 與 Python 數學工作池；前端採 Vue 3／TypeScript／Vite。
- PostgreSQL／pgvector 儲存權威與檢索資料，Redis 處理佇列與快取，MinIO 保存大型產物。AI 透過可替換 Gateway 路由。
- 本地使用同一份 Docker Compose 設計：macOS 開發，Windows 11 + WSL2 架設；平台差異使用覆寫檔，沿用 ADR-006。
- 公式以 DSL／AST 為權威表示；搜尋結果經獨立驗證與審核才進入可推薦記憶。
- 有限資料可能無法唯一識別公式；數值相符、樣本外支持、符號推導與形式化證明各有不同證據要求。
