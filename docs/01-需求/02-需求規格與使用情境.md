# 02｜需求規格與使用情境

> AXIOM v2.7 設計規格｜文件 ID AX-02｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

研究員提交任務時必須填寫研究目的（描述／預測／機制）、自變數、目標變數、可用資料、時間順序、硬性約束與計算預算。若資料缺少必要欄位，阻止執行並提供修復指引。

### 使用者旅程

研究員建立專案 → 上傳資料並設定語意／單位 → 查看品質與可識別性 → 啟動研究 → 觀察候選公式與殘差 → 挑選推演／驗證 → 比較模型 → 儲存研究結論與不確定性 → 新數據到來時增量重驗。

### 權限角色

MVP 不提供匿名訪客；viewer 僅讀 ACL 授權結果；研究員可建立研究與候選；審核員可核准經驗晉級；管理員可管理模型、配額與資料政策；服務帳號只取得最小權限。

## 當期必要範圍

M1～M3 的 MUST 為 REQ-001、002、003、009、010；REQ-004／005 在 M4 才是 MUST，REQ-006～008 依 AX-30 的 M5～M7。MVP 僅單變量實數顯式函數與 AX-10 v1 算子；記憶、外部模型、遞迴、ODE 及自動訓練不構成 MVP 前置依賴。每個需求驗收映射以 AX-46 為準。

## 優先級與首期安全基線

P0～P4的功能排序不等同NFR交付時點。NFR-004的硬成本／研究額度、NFR-005的基本鍵盤與可讀性、NFR-007的租戶／作者與資料治理，雖有後續增強項，首期基線仍是M1～M3必過，不能以表中P1延到M4；延後的是進階最佳化或治理自動化。NFR-001／002／003／006亦按AX-46與D-01／06驗證。M1～M3任何必需安全／正確性案例未通過就不得對外發布，沒有「P1所以可以跳過」的例外。
