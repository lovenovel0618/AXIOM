# 14｜推演一般化與形式化證明

> AXIOM v2.1 整合基線｜文件 ID AX-14｜狀態：設計基線（未實作）｜2026-10-19

## 1. 文件定位與決策摘要

推導圖的邊型別包括 differentiate/integrate/substitute/generalize/restrict/equivalent/approximate/contradicts；每條邊記錄前提、步驟、檢查器、版本及反例。Lean proof status 與經驗證據分離。

**設計原則**：每個規範都要能轉換成可測試的行為、可追溯的證據或明確的工程決策；凡屬目標數字均非已實測結果。

## 2. 章節專屬規格

### 推演操作

微分、積分、代換、極限、級數、漸近、對稱性、不變量、反函數、變數擴充、參數化通式、ODE/遞迴推導；每一步保存原公式、規則、假設與結果。

### 證明等級

數值測試 → 符號等價／解析推導 → Lean 4 等形式化證明核心確認 → 現實世界的獨立實證驗證。前三者不等同第四者；未證明命題保持 open 狀態。

### 演化圖

節點：公式、命題、假說、模型家族；邊：derived_from、generalizes、specializes、contradicts、equivalent_under、supported_by；每條邊含假設、證據、版本。

### 限制

LLM 只能提出證明草案；SymPy 無法化簡不代表命題錯誤；Lean 核心驗證只保證形式化定理在所列公理／假設下成立。

## 3. 能力分解與詳細規格

### 3.1 資料語意模型

區分連續量、計數、比例、機率、類別、時間、空間、序列索引；記錄單位、精度、觀測機制、時間戳與時區、量測儀器、資料來源。

**強制規則／例外處理**：單位不相容的公式禁止進入候選池；缺少語意時以未知標記而非自行假定。

### 3.2 公式表示與合法性

公式使用受限制 DSL、具型別 AST、明確定義域、參數與約束；分開儲存機器結構、SymPy 表示、LaTeX 顯示、數值求值圖。

**強制規則／例外處理**：不使用任意 eval；驗證奇異點、複數域、單位一致性及數值溢位。

### 3.3 多策略搜尋

快速基線→形狀/頻譜/差分特徵→公式家族→符號迴歸→片段重組→殘差再探索；每一階段有成本上限與早停條件。

**強制規則／例外處理**：至少保留部分預算做獨立探索，避免經驗造成搜尋偏差。

### 3.4 高精度與不確定性

數值精度與測量準確度分開；在 float64 失穩時可提升至任意精度；以參數、結構、觀測與分布不確定性分層輸出。

**強制規則／例外處理**：增加顯示小數位不能視為增加證據。

### 3.5 推演與證明

公式延伸、一般化、微分積分、ODE、遞迴、對稱性、不變量、極限；推導步驟保存假設、使用規則、證明狀態與反例。

**強制規則／例外處理**：符號化簡不等於形式化證明；形式化證明只在受信任的 proof checker 通過後標記。

### 3.6 多資料關聯

雙序列先檢查對齊、延遲、混雜與多重檢定；互斥需事件定義及聯合發生機率，不得用負相關替代；多變量再處理條件依賴與高階交互。

**強制規則／例外處理**：觀測相關性不得自動標示為因果。

## 4. 關鍵技術決策與邊界條件

1. 推導步驟必須引用前一步公式版本、假設、使用的規則、目標命題與工具版本。

2. 符號計算的 timeout、假設不足、條件化結果都必須是合法結果狀態，不可自動改成成功。

3. Lean 4 等證明器的受信任核心檢查成功才標記 formal proof；AI 撰寫的 proof text 未經檢查只算草稿。

4. 公式一般化須比較多個案例的共同結構，並在留出案例上檢查新通式是否有預測力。

## 6. 失敗情境與降級策略

| 失敗或風險 | 系統反應 | 留存證據 |
|---|---|---|
| 輸入不符合「推演一般化與形式化證明」要求 | 拒絕執行並提供可修正的欄位錯誤 | 輸入版本、驗證規則、錯誤代碼 |
| 依賴服務中斷或超時 | 有限次重試；超出預算即終止並保存 checkpoint | 服務版本、耗時、重試紀錄 |
| 結果彼此衝突或證據不足 | 保留候選及歧義，不提升證據等級 | 候選集合、反例、驗證集 |
| 資源配額超出 | 中止重運算，保留已完成的可信部分結果 | CPU/GPU 秒、記憶體峰值、任務狀態 |

## 7. 可執行驗收案例

**AC-14-01 正常路徑**：給定完整合法的輸入、固定資料版本與計算預算，執行「推演一般化與形式化證明」流程，必須產出可追溯的結果與完成狀態。

**AC-14-02 異常路徑**：故意提供缺欄、錯誤型別、超時或不合法狀態，必須得到明確診斷且不得產生已驗證的假結果。

**AC-14-03 重現性**：在固定輸入、版本、隨機種子與執行環境下重跑，輸出應符合預先定義的決定性或容差標準。

**AC-14-04 權限與審核**：未授權角色不得讀取或發布研究資料；審核者能查詢完整證據鏈。
