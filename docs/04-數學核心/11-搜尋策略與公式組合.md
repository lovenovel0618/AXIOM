# 11｜搜尋策略與公式組合

> AXIOM v2.6 設計規格｜文件 ID AX-11｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

搜尋採分層候選：常數／線性／多項式→傅立葉與趨勢→指數與有理函數→分段／遞迴→符號迴歸→公式片段組合。每候選保存初始化來源、最佳化軌跡、失敗原因與運算成本。

## 章節專屬規格

### 搜尋家族

線性/多項式、三角/Fourier、指數/對數、Gaussian/RBF、sigmoid、分段/spline、離散遞迴、ARIMA/狀態空間、ODE/SINDy、符號迴歸；依資料語意啟用，不全量無差別窮舉。

### 搜尋策略

Stage A 快速基線；Stage B 特徵引導候選；Stage C 符號迴歸/演化搜尋；Stage D 公式片段加法、乘法、巢狀、調變、分段組合；Stage E 殘差再探索。保留獨立探索配額避免歷史偏見。

### 排名與停止

以樣本外誤差、複雜度、數值穩定性、適用域、計算成本作 Pareto 排序；重複候選合併；預算耗盡或無邊際改善則停止，輸出不確定性。

### 演算法套件

NumPy、SciPy、SymPy、PySR、scikit-learn、statsmodels、PySINDy、Optuna、Polars；依授權與部署條件確認版本相容性。

## 關鍵技術決策與邊界條件

1. 每一策略宣告適用資料類型、最少樣本、運算子集合、時間預算、資源類型及候選上限。

2. 先對低複雜度家族進行 baseline；只有殘差顯示未捕捉結構時才擴展至更昂貴的家族。

3. 複合式組合允許加法、乘法、巢狀、調變、分段；每增加片段都必須比較 development 改善量與複雜度懲罰。

4. 排名以 Pareto front 保留準確度、複雜度、穩定性與成本的不同權衡，避免單一加權分數掩蓋極端缺點。

## MVP 三策略與評估資料

線性最小平方、2～3 次多項式、固定頻率諧波字典為 M2 三種基線；資料語意不適用時保留拒用理由。所有排名、片段選擇及成本收益只讀 fit/development；最終 final_test 只在候選凍結後由 Evaluator 評一次，協定以 AX-05／28 為準。符號迴歸與記憶推薦不替代三策略基線。

## M2 基線演算法的固定設定

三策略都只使用 fit 列估參數，以 development MAE／複雜度／成本排序。線性先產常數零、fit 均值及含截距最小平方；多項式測 degree=2、3，各需至少 degree+1 個不同 x；諧波策略固定單頻字典 omega=2*pi*k/T（k=1,2,3，T=max(x_fit)-min(x_fit)），逐一擬合 intercept+a*sin(omega*x)+b*cos(omega*x)，至少 4 個不同 x 且 T>0。頻率不能由 final_test 選擇；資料混疊／不足時保存診斷。

數值求解採 QR 或 SVD，禁止直接反解 normal-equation matrix；fit 輸入以 fit 均值／尺度正規化並保存逆變換，結果 AST 對回原始變數。float64 的 rank 判定預設相對最大 singular value 門檻 1e-12，rank 不足保留退化診斷、不強行給唯一參數。固定頻率在 AST 用有相應逆變數單位的 param，lower=upper，不能以無量綱常數冒充帶單位係數。

M2 公開 B-LINE 必須恢復線性等價候選；三策略都必須有執行或可驗證的不適用紀錄，而非要求每種策略對所有輸入都成功。泛化成功率仍待 D-03 的盲測，不由本公開案例推導。

## 候選到凍結的選擇

Candidate可含多個起點／optimizer的FitRun。只在development上選一個合格FitRun，按固定MAE、複雜度、成本及id的決定性tie-break建立FrozenCandidate；同rank不能重複。FrozenSubmission的Top-k按development_rank固定，看到final結果後不得改FitRun／binding／排名。式族命中、參數誤差與代入後等價分開，協定見AX-28。

上述fit-only規則適用搜尋與development選模階段；選模結束後，僅可依AX-28已預註冊政策另建FIT_DEVELOPMENT任務重新擬合，不能將聯集訓練誤差用來重排候選。
