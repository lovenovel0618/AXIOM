# 12｜參數最佳化與數值精度

> AXIOM v2.1 整合基線｜文件 ID AX-12｜狀態：設計基線（未實作）｜2026-10-19

## 1. 文件定位與決策摘要

非線性最佳化採多起點與參數界限，避免單次局部最優；報告 Hessian/條件數或 profile likelihood 的可識別性線索；數值不穩定時才提高 mpmath 精度，且保存精度決策原因。

**設計原則**：每個規範都要能轉換成可測試的行為、可追溯的證據或明確的工程決策；凡屬目標數字均非已實測結果。

## 2. 章節專屬規格

### 最佳化層級

解析解優先；非線性最小平方法；多起點全域搜尋；有界最佳化；混合離散結構與連續參數分層求解；依參數可識別性選擇正則化或貝氏估計。

### 精度策略

預設 float64；對消、極端尺度、近奇異點啟用 mpmath 任意精度；紀錄精度位數、條件數、溢位/下溢、計算時間；高精度不能補回測量資訊。

### 敏感度

參數 profile likelihood、bootstrap 或可信區間、Jacobian 條件數、Hessian 退化檢查；必要時回報參數組合不可辨識，而非給虛假的精確係數。

## 3. 能力分解與詳細規格

### 3.1 資料語意模型

區分連續量、計數、比例、機率、類別、時間、空間、序列索引；記錄單位、精度、觀測機制、時間戳與時區、量測儀器、資料來源。

**強制規則／例外處理**：單位不相容的公式禁止進入候選池；缺少語意時以未知標記而非自行假定。

### 3.2 公式表示與合法性

公式使用受限制 DSL、具型別 AST、明確定義域、參數與約束；分開儲存機器結構、SymPy 表示、LaTeX 顯示、數值求值圖。

**強制規則／例外處理**：不使用任意 eval；驗證奇異點、複數域、單位一致性及數值溢位。

### 3.3 多策略搜尋

快速基線→形狀/頻譜/差分特徵→公式家族→符號迴歸→片段重組→殘差再探索；每一階段有成本上限與早停條件。

**強制規則／例外處理**：至少保留部分預算做獨立探索，避免經驗造成搜尋偏差。

### 3.4 高精度與不確定性

數值精度與測量準確度分開；在 float64 失穩時可提升至任意精度；以參數、結構、觀測與分布不確定性分層輸出。

**強制規則／例外處理**：增加顯示小數位不能視為增加證據。

### 3.5 推演與證明

公式延伸、一般化、微分積分、ODE、遞迴、對稱性、不變量、極限；推導步驟保存假設、使用規則、證明狀態與反例。

**強制規則／例外處理**：符號化簡不等於形式化證明；形式化證明只在受信任的 proof checker 通過後標記。

### 3.6 多資料關聯

雙序列先檢查對齊、延遲、混雜與多重檢定；互斥需事件定義及聯合發生機率，不得用負相關替代；多變量再處理條件依賴與高階交互。

**強制規則／例外處理**：觀測相關性不得自動標示為因果。

## 4. 關鍵技術決策與邊界條件

1. 區分資料精度、參數輸出位數、演算法浮點精度與真實測量準確度，介面必須各自標示。

2. 最適化採多起點初始化與參數約束；記錄收斂訊息、梯度或 Jacobian 條件、重啟次數與失敗點。

3. 使用時間前推切分、blocked CV 或依研究類型選定的 holdout；不能隨機打亂有時間依賴的序列。

4. 精度升級門檻由條件數、消去誤差、近奇異點、對照高精度差異觸發；避免全程高精度造成不必要成本。

## 6. 失敗情境與降級策略

| 失敗或風險 | 系統反應 | 留存證據 |
|---|---|---|
| 輸入不符合「參數最佳化與數值精度」要求 | 拒絕執行並提供可修正的欄位錯誤 | 輸入版本、驗證規則、錯誤代碼 |
| 依賴服務中斷或超時 | 有限次重試；超出預算即終止並保存 checkpoint | 服務版本、耗時、重試紀錄 |
| 結果彼此衝突或證據不足 | 保留候選及歧義，不提升證據等級 | 候選集合、反例、驗證集 |
| 資源配額超出 | 中止重運算，保留已完成的可信部分結果 | CPU/GPU 秒、記憶體峰值、任務狀態 |

## 7. 可執行驗收案例

**AC-12-01 正常路徑**：給定完整合法的輸入、固定資料版本與計算預算，執行「參數最佳化與數值精度」流程，必須產出可追溯的結果與完成狀態。

**AC-12-02 異常路徑**：故意提供缺欄、錯誤型別、超時或不合法狀態，必須得到明確診斷且不得產生已驗證的假結果。

**AC-12-03 重現性**：在固定輸入、版本、隨機種子與執行環境下重跑，輸出應符合預先定義的決定性或容差標準。

**AC-12-04 權限與審核**：未授權角色不得讀取或發布研究資料；審核者能查詢完整證據鏈。
