# 13｜可識別性不確定性與主動採樣

> AXIOM v2.8 設計規格｜文件 ID AX-13｜狀態：待實作、待驗收｜2026-10-20

## 主張範圍

結構可識別性是在指定模型家族／參數域／觀測機制下的理論性質；實務可識別性則受當前樣本、噪聲及採樣影響。有限候選集合上未找到替代模型，不能證明全體公式唯一。

## 判定程序

1. 固定資料域、量測誤差、split、允許家族與 practical_margin；方法見 AX-28。
2. 參數估計保存多起點結果、約束、Jacobian／Hessian 診斷；對非線性或退化問題用 profile 或適用 bootstrap，不自動把 Hessian 逆當可靠信賴區間。
3. 對各候選做獨立域合法性與 development 評估。依 AX-28 的 paired loss 區間區分勝出、容差內等效及未能下結論；不可把不顯著直接當相同。
4. 至少兩個未獲符號等價證據的候選都與觀測誤差相容且缺區分證據，回 AMBIGUOUS。缺誤差模型、資料或評估方法時回 INSUFFICIENT_EVIDENCE。
5. 最終 holdout 只在凍結後查詢；報告觀測、參數、結構、數值與漂移的不確定性，不合併為單一 confidence。

## 採樣建議

可控制輸入時在共同合法域內，以候選預測分歧／量測噪聲／成本排序可行點，記錄 objective、候選版本、安全限制與預期分歧。預測分歧最大但出域、不可操作或違反安全限制的點不能建議執行。不可控制時只提出觀測窗口／需求，不自動操作實驗。新採樣資料屬新 DatasetVersion，不能回填舊 final_test。

| ID | 輸入 | 預期 |
|---|---|---|
| AC-13-01 | B-AMBIG 的 sin(x)/x 及量測界 | AMBIGUOUS；保留兩個模型與分歧點 |
| AC-13-02 | 只有單一候選且未證明完備的搜尋空間 | 不得回唯一真式，只報最佳已知候選 |
| AC-13-03 | 禁止 x>0.5，但兩模型在 x=1 分歧最大 | 不建議 x=1，說明限制並改排可行點 |
| AC-13-04 | 參數 a*b 可辨但 a、b 各自不可辨 | 保存乘積及多解／區間，不輸出單一精確係數 |

## 正向預測與逆向識別的差別

參數反演、函數逆解、相容生成系統及因果反事實分開，完整定義依AX-51。多解／ill-conditioned／未知都是合法結果；active sampling建議應能區分競爭解釋且受資料取得政策限制，不能自動採集真人或外部資料。發現有效反例需固定claim／binding／域，optimizer未收斂則轉AX-50數值不確定，不否定整個公式家族。
