# 09｜數據語意與前處理

> AXIOM v2.5 設計規格｜文件 ID AX-09｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

前處理禁止預設補值或去極端值；每次清理保留 before/after、理由與統計影響。時間序列切分時避免將未來資訊帶入過去，頻譜分析需檢查非等距採樣與 aliasing。

## 章節專屬規格

### 資料類型

連續/離散、自變數/因變數、時間/空間/事件、單位與量綱、測量/模擬、獨立/重複觀測、缺失機制、取樣頻率、量化位數、觀測誤差。

### 處理規則

原始資料不可覆寫；每個轉換產生 lineage；標準化、插值、去趨勢、去噪需保存參數及逆變換；缺值不可默認填零；時間序列需避免未來資料洩漏。

### 資料品質報告

有效筆數、唯一自變數數、間距分布、缺值率、離群比例、飽和/截斷、精度估計、採樣偏差、單位衝突、時間戳異常；附建議的搜尋限制。

## 匯入格式及版本結果

MVP 支援 UTF-8 CSV（header 必填、禁止重複欄名）、JSON records array、Parquet scalar columns。單變量 inputs 一欄、target 一欄；其餘欄可保留但不自動作特徵。逐列保存原始 row_id；空值、非有限數、混合型別、重複 timestamp 都以品質報告明列，禁止靜默丟列／填零。超限回 AX-21 錯誤；不支援巢狀 JSON、公式巨集、可執行物件。使用者修正產生新版本與 lineage，不改原檔。轉換先切 split 再 fit；驗收門檻與資料有效性標記依 AX-28。

預註冊的fit+development最終重新擬合是AX-28定義的明確例外：僅在選模結束後，依固定政策在聯集重新fit前處理並另存產物／fit_row_ids／hash。final與gap列仍禁止參與，原fit-only轉換不可覆寫。
