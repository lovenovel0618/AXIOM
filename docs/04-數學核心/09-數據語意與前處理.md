# 09｜數據語意與前處理

> AXIOM v2.8 設計規格｜文件 ID AX-09｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

前處理禁止預設補值或去極端值；每次清理保留 before/after、理由與統計影響。時間序列切分時避免將未來資訊帶入過去，頻譜分析需檢查非等距採樣與 aliasing。

## 章節專屬規格

### 資料類型

連續/離散、自變數/因變數、時間/空間/事件、單位與量綱、測量/模擬、獨立/重複觀測、缺失機制、取樣頻率、量化位數、觀測誤差。

### 處理規則

原始資料不可覆寫；每個轉換產生 lineage；標準化、插值、去趨勢、去噪需保存參數及逆變換；缺值不可默認填零；時間序列需避免未來資料洩漏。

### 資料品質報告

有效筆數、唯一自變數數、間距分布、缺值率、離群比例、飽和/截斷、精度估計、採樣偏差、單位衝突、時間戳異常；附建議的搜尋限制。

## 匯入格式及版本結果

MVP 支援 UTF-8 CSV（header 必填、禁止重複欄名）、JSON records array、Parquet scalar columns。單變量 inputs 一欄、target 一欄；其餘欄可保留但不自動作特徵。逐列保存原始 row_id；空值、非有限數、混合型別、重複 timestamp 都以品質報告明列，禁止靜默丟列／填零。超限回 AX-21 錯誤；不支援巢狀 JSON、公式巨集、可執行物件。使用者修正產生新版本與 lineage，不改原檔。轉換先切 split 再 fit；驗收門檻與資料有效性標記依 AX-28。

預註冊的fit+development最終重新擬合是AX-28定義的明確例外：僅在選模結束後，依固定政策在聯集重新fit前處理並另存產物／fit_row_ids／hash。final與gap列仍禁止參與，原fit-only轉換不可覆寫。

## 原始欄位與公式變數映射

SemanticProfile.inputs及target各必填name、source_column與unit。name仍為DSL的ASCII識別字；source_column為解析後原始欄名，支援UTF-8及空格／括號，最長256字元，按完整字串精確比對，不默認trim、改大小寫或按欄位位置猜測。例如原始「時間（秒）」可映射name=x，原始「位移（公分）」可映射name=y；單位及數值轉換由下節conversion顯式確認，欄位映射不等於量綱轉換。

建立版本時驗證來源欄存在、同一來源欄不可同時作input與target、name唯一且不與公式參數衝突。未知欄回SOURCE_COLUMN_NOT_FOUND，角色衝突回SOURCE_COLUMN_CONFLICT；重複原始欄名仍在INGEST拒絕。JSON/Parquet同樣用其欄鍵／欄名，不接受巢狀路徑猜測。time_column／group_column使用來源欄名，與DSL alias分開。

映射隨ResearchVersion不可變，PROFILE及所有projection保留來源欄名→alias對照，模型輸出AST只用alias；報告顯示兩者並可追溯原始row_id。來源檔重命名／欄名修改屬新DatasetVersion；改研究角色或映射建立新ResearchVersion，不能原地修舊證據。

## 單位數值契約與盲測前處理邊界

SemanticProfile每個input／target必填conversion={source_unit,scale,offset}，數值用十進位字串。canonical_value = source_value × scale + offset，scale必須大於0；unit仍表示canonical SI的七維量綱，不負責比例或原點。source_unit是人工確認的來源標籤，系統不能由名稱猜比例；已是SI也明填scale=1、offset=0。cm→m用0.01／0，攝氏→K用1／273.15；仿射轉換只在資料入口執行，DSL內不加入攝氏加減運算。無法明確轉成SI的任意單位在MVP拒絕，不能標成無量綱繼續。建立時以十進位精確運算驗證，轉數值引擎前依固定precision記錄捨入與溢位；非法值回422 UNIT_CONVERSION_INVALID。

固定domain、measurement_resolution、absolute_error_bound及practical_scale_override一律使用canonical目標／輸入單位，resolution與非null誤差界必為正。報告顯示canonical值，切換來源顯示用(source_value=(canonical-offset)/scale)，誤差／resolution只除scale，不減offset。相同比例單位轉換後的canonical觀測用於曝光content token，不能用cm改m重取盲測資格；此canonical化屬既有exposure_fingerprint_version=1.0的未部署草案，實作後變更需可核對舊token的版本遷移。

先固定split，再在fit列學習標準化、補值或去噪參數；MVP不自動補值。被選為input／target的缺值、非有限數、轉換溢位或錯型使PROFILE品質不通過並回DRAFT，保留row_id，不能靠刪除final失敗列提高coverage。非使用欄的問題不必阻擋研究。final品質檢查由可信服務執行，PROJECT報告只含經遮罩的阻擋原因，不含final標籤分布、均值、極值、逐列錯誤或可推回值的計數；完整診斷另存SEALED_DETAIL。fit-only統計不能混入final再供搜尋限制、誤差尺度或預設domain使用。

SemanticProfile.group_column必填可null，非null時須精確對應原始來源欄，ObservationSplit.group_column必須相同並以GROUPED_ROWS切分；null表示使用者聲明無群組依賴，不能只靠split.kind反推聲明。宣告time_ordered=true時必用TIME_ORDERED，不接受RANDOM_ROWS或EXPLICIT繞過時間政策；群組依賴必用GROUPED_ROWS，MVP不支援同時時間及群組約束，明確拒絕而非任選其一。EXPLICIT只供已確認獨立觀測；聲明及固定來源欄隨版本保存，可信服務仍驗證時間／群組不交叉。

## 上傳與解析資源限制

簽名PUT過期時間不代表真正單次使用。儲存端必須條件式建立不可覆寫key，或保留版本並讓complete鎖定唯一object_version；原始檔永不指向可變latest。complete鎖UploadRecord，核對tenant、到期、checksum、實際大小及immutable version，原子標COMPLETED並建立唯一INGEST。已COMPLETED之後重送complete即使超過24h也回同一run；晚到PUT不能換該run的版本。未完成時版本／checksum變動回UPLOAD_OBJECT_CHANGED；新簽名需新session，MVP不提供斷點續傳。相同dataset／內容hash的併發匯入，以唯一鍵取回既有DatasetVersion，INGEST成功引用它，不建立第二份版本或因unique exception卡住。

50MiB是傳輸上限，並非解壓後安全上限。INGEST還需固定ImportLimits設定：max_rows、max_columns、max_cell_utf8_bytes、max_decoded_bytes、max_parse_seconds皆正整數，入列前必填並受worker記憶體上限約束；沒有設定拒絕啟動，正式值依D-01容量配置。解析CSV／JSON／Parquet逐批累計，超任一限制立即停止、回413 IMPORT_LIMIT_EXCEEDED並隔離暫存，禁止先全量載入再檢查。壓縮Parquet、超長字串、深層JSON、偽副檔名與解析超時都需負例；內容以實際parser驗證，不信任Content-Type。過期／ABORTED session暫存由有界GC清除，GC不得刪除已被完整Artifact registry引用的物件。

## 從人工語意設定到結構建議

AX-49的StructureAssessment由fit可讀資料提出多種結構及維度估計，使用者可確認或修正時間、座標、群組、欄位及單位。MVP的自動偵測是可追溯建議，不自動擴充CreateResearchVersion.inputs上限。更換資料表徵仍保存原始row依賴及轉換recipe，先切分再學映射；原資料、canonical SI、開發／final權限和不靜默刪列規則不變。
