# 16｜經驗記憶與檢索架構

> AXIOM v2.1 整合基線｜文件 ID AX-16｜狀態：設計基線（未實作）｜2026-10-19

## 1. 文件定位與決策摘要

記憶查詢先用資料類型、單位、域、採樣密度、噪聲級硬過濾，再混合 embedding/特徵/AST 重排；回傳經驗時必須附 evidence_id、適用域、成功與失敗統計。

**設計原則**：每個規範都要能轉換成可測試的行為、可追溯的證據或明確的工程決策；凡屬目標數字均非已實測結果。

## 2. 章節專屬規格

### 記憶分類

案例、公式、片段、策略、失敗、證據、推導、證明、一般化、演化、訓練樣本；統一保存 context-action-outcome-evidence 與來源。

### 檢索方式

混合：統計特徵近鄰、頻譜與形狀相似、公式 AST 子圖、文字語意向量、領域／定義域篩選；分數校準與 rerank；避免只用 embedding 判斷數學相似。

### 寫入與治理

原始事件不可覆寫；摘要可重建；候選經驗須經獨立驗證才可晉級；新反例可降權、撤銷、標記失效；去重依資料指紋＋AST 等價類＋實驗上下文。

### 負遷移

持續比較 memory-on / memory-off，記錄各情境下的搜尋收益；若歷史案例導致效果下降，降低推薦權重但保留反例。

## 3. 能力分解與詳細規格

### 3.1 記憶分層

原始實驗紀錄、公式與片段、搜尋策略、反例、推導證明、歸納知識及訓練樣本分庫管理；以穩定 ID 關聯，不以 LLM 文字摘要代替原始證據。

**強制規則／例外處理**：每筆記憶必須追溯資料集、演算法版本、模型版本、驗證與適用域。

### 3.2 相似檢索

融合統計特徵、頻譜、形狀、公式 AST 與語意向量；先做硬條件過濾，再做候選召回與重排。

**強制規則／例外處理**：同一來源衍生的近重複案例不得讓檢索品質測試灌水。

### 3.3 記憶生命週期

候選→已驗證→可檢索→降權→封存／撤銷；當新證據衝突時保留歷史版本並建立衝突連結。

**強制規則／例外處理**：錯誤記憶必須能追蹤曾影響哪些研究結果。

### 3.4 理論演化圖

公式節點、假說節點、資料節點、證據節點與推導邊；邊記錄變換、假設、時間與驗證狀態。

**強制規則／例外處理**：圖譜是關係索引而非真理來源；節點可信度由證據決定。

## 4. 關鍵技術決策與邊界條件

1. 檢索品質以 Recall@k、nDCG、引用證據完整率與負遷移率衡量，且按資料家族分層。

2. 經驗保留 Context、Action、Outcome、Evidence、ApplicableDomain、FailureModes、Version、Source。

3. 成功案例與失敗案例都可以檢索；失敗案例不能當作推薦答案，只能作反例與策略排除線索。

4. 更新權重前需有足夠對照實驗，避免一次失敗就永久封殺有效方法。

## 6. 失敗情境與降級策略

| 失敗或風險 | 系統反應 | 留存證據 |
|---|---|---|
| 輸入不符合「經驗記憶與檢索架構」要求 | 拒絕執行並提供可修正的欄位錯誤 | 輸入版本、驗證規則、錯誤代碼 |
| 依賴服務中斷或超時 | 有限次重試；超出預算即終止並保存 checkpoint | 服務版本、耗時、重試紀錄 |
| 結果彼此衝突或證據不足 | 保留候選及歧義，不提升證據等級 | 候選集合、反例、驗證集 |
| 資源配額超出 | 中止重運算，保留已完成的可信部分結果 | CPU/GPU 秒、記憶體峰值、任務狀態 |

## 7. 可執行驗收案例

**AC-16-01 正常路徑**：給定完整合法的輸入、固定資料版本與計算預算，執行「經驗記憶與檢索架構」流程，必須產出可追溯的結果與完成狀態。

**AC-16-02 異常路徑**：故意提供缺欄、錯誤型別、超時或不合法狀態，必須得到明確診斷且不得產生已驗證的假結果。

**AC-16-03 重現性**：在固定輸入、版本、隨機種子與執行環境下重跑，輸出應符合預先定義的決定性或容差標準。

**AC-16-04 權限與審核**：未授權角色不得讀取或發布研究資料；審核者能查詢完整證據鏈。

## 8. 實作任務分解與交付物

| 順序 | 工作項 | 完成定義 |
|---|---|---|
| 1 | 規格與輸入輸出契約 | 完成 schema、狀態與錯誤定義，審查通過 |

| 3 | 邊界與反例測試 | 正常、異常、資源限制及證據不足皆有測試 |
