# 16｜經驗記憶與檢索架構

> AXIOM v2.8 設計規格｜文件 ID AX-16｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

記憶查詢先用資料類型、單位、域、採樣密度、噪聲級硬過濾，再混合 embedding/特徵/AST 重排；回傳經驗時必須附 evidence_id、適用域、成功與失敗統計。

## 章節專屬規格

### 記憶分類

案例、公式、片段、策略、失敗、證據、推導、證明、一般化、演化、訓練樣本；統一保存 context-action-outcome-evidence 與來源。

### 檢索方式

混合：統計特徵近鄰、頻譜與形狀相似、公式 AST 子圖、文字語意向量、領域／定義域篩選；分數校準與 rerank；避免只用 embedding 判斷數學相似。

### 寫入與治理

原始事件不可覆寫；摘要可重建；候選經驗須經獨立驗證才可晉級；新反例可降權、撤銷、標記失效；去重依資料指紋＋AST 等價類＋實驗上下文。

### 負遷移

持續比較 memory-on / memory-off，記錄各情境下的搜尋收益；若歷史案例導致效果下降，降低推薦權重但保留反例。

## 關鍵技術決策與邊界條件

1. 檢索品質以 Recall@k、nDCG、引用證據完整率與負遷移率衡量，且按資料家族分層。

2. 經驗保留 Context、Action、Outcome、Evidence、ApplicableDomain、FailureModes、Version、Source。

3. 成功案例與失敗案例都可以檢索；失敗案例不能當作推薦答案，只能作反例與策略排除線索。

4. 更新權重前需有足夠對照實驗，避免一次失敗就永久封殺有效方法。

## 共用規則

版本、錯誤、證據與審查規則見 [AX-48 共用契約與文件治理](<../00-總覽/48-共用契約與文件治理.md>)；本章的專屬限制及驗收條件仍須同時滿足。

## 快取與知識重用的完整身分

搜尋／fit／評估快取鍵至少固定tenant、資料內容及row/split hash、SemanticProfile含conversion的hash、domain、DSL及binding、evaluation policy、plugin config及environment digest；不將只有equation hash視為同一任務。命中後仍核對目前ACL、access_class、來源有效性及曝光資格，不能由快取跳過final slot／seal消耗或研究成本裁決。物件不可讀／被撤銷即停止一般檢索；重建索引延遲不能使舊entry繼續可用。快取輸出只重用相同數學設定，執行成本與來源成本分別記錄，不重複宣稱本次重算。

公開摘要僅供授權使用者閱讀；依AX-26，RELEASED_AGGREGATE也不能進入Solver搜尋、檢索、embedding或訓練。原final內容／token／逐點殘差同樣禁止進入Solver prompt或跨租戶索引。記憶學習只接受另有合法PROJECT來源及獨立授權的資料，不能把「摘要已公開」當作訓練許可。publication claim為REFUTATION或DIAGNOSTIC時存負面／不足案例，不能與SUPPORTED公式混成正面訓練樣本；withdrawal沿claim及lineage停用後代樣本，已訓練模型是否需回退沿AX-19政策，不宣稱刪一列即可機器遺忘。

## 經驗不是未經驗證的摘要

ATME的原始觀測、經驗候選與BENCHMARK_VERIFIED策略分層；支持與反對case、條件、來源版本、選擇機會及不確定性都保留。優先RAG／可撤回記憶，轉規則或權重需AX-52的獨立晉級。軟性淘汰及HRR不能把歷史先驗變成硬禁家族；已釋出摘要依AX-26仍不可進Solver記憶，不能因這次新增Token整理放寬。
