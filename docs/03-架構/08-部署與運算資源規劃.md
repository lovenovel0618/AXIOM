# 部署與運算資源規劃

> AXIOM | 規劃基線 v1.0 | 2026-10-19 | 文件：`03-架構/08-部署與運算資源規劃.md`

## 文件目的
定義開發、測試、生產與資源隔離。

## 環境分層

Local Docker Compose：Django、Vue、PostgreSQL、Redis、MinIO、Ollama 選配；CI：隔離基準與安全掃描；Staging：性能與故障演練；Production：獨立資料與工作池。

## 本地容器化（開發與基準）

本地開發以 Docker Compose 統一環境，服務清單、資料卷、環境變數、健康檢查與 macOS 注意事項見 `03-架構/41-Docker本地架設指南.md`。原則：

- 容器映像與組態可重建，Redis 與容器本機狀態不作為唯一永久資料來源。
- 依賴以健康檢查表達，不以固定等待時間取代；必要服務不健康時不提供服務。
- proof／sandbox worker 於本地亦維持無外網、唯讀檔案系統與非 root 執行。
- Mac 無 GPU 直通，gpu 佇列不啟用；Ollama 以宿主原生服務為預設路由。

## 工作池

light：資料清理／特徵；search：CPU 符號迴歸；precision：mpmath 高精度；gpu：本地模型推理；proof：受限形式化驗證。各佇列獨立配額、超時、併發、記憶體上限。

## 容量方法

先測單次工作 CPU 秒、記憶體峰值、候選數、資料量與 I/O；按到達率與 P95 服務時間估算併發，再壓測。避免未實測就宣稱固定硬體規格足夠。

## 復原

每日一致性備份與物件版本化；定期恢復演練；RPO/RTO 由產品等級決定；長任務以 checkpoint 減少重跑。
