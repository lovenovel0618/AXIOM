## 公開測試資料

資料與固定 oracle 存在 [benchmark-v1.json](<../contracts/benchmark-v1.json>)，供 M1 的求值／評估與 M2 搜尋 smoke test。公開案例不宣稱未知結構泛化。產物需記錄 split、DSL、metric_version、環境與 budget。

| ID／案例 | 固定輸入／設定 | 預期判定與反例 |
|---|---|---|
| AC-36-01／B-LINE | x=0..9、y=2x+1；fit 0..5、dev 6..7、final 8..9；單位無量綱 | 固定候選 y=2x+1 應逐點通過 1e-10 容差；搜尋線性策略應找回線性家族；凍結的精確binding另測代入後等價，浮點估計只按參數誤差／預測容差評分。改 y_final 不得改 FitRun 參數 |
| AC-36-02／B-AMBIG | x=[-0.1,-0.05,0,0.05,0.1]、y=sin(x)，絕對量測界 0.001 | sin(x)、x 都相容，outcome=AMBIGUOUS；x=1 預測差大於量測界但仍需確認可採樣，禁止聲稱找到唯一真式 |
| AC-36-03／B-DOMAIN | x=[-1,0,1]，候選 x/x、對照 1；0 為必評點 | 前者 coverage=2/3，DOMAIN_VIOLATION，不可去掉 0 後宣布恆等；若另建排除 0 的域則另記版本 |
| AC-36-04／B-NOISE | fixture 固定序列與候選 y=10，零 baseline | 候選在固定 final 資料 MAE/RMSE 都較差，不能晉級；不因本案例命名為 noise 就宣稱已證明隨機 |

B-AMBIG 是「觀測誤差界下候選相容」測試，不套一般統計等效區間；只有少數點時不虛構 bootstrap 證據。fixture 的 final 值是公開測試 oracle，不可用來宣稱已完成私有盲測。

## 端到端輸入與動作

以 B-LINE 依序建立 Dataset、upload/complete、DatasetVersion、Research、ResearchVersion、PROFILE、SEARCH、候選比較、FrozenCandidate／FrozenSubmission、VALIDATE 與 ReviewDecision。MVP 需至少三策略均有執行或不適用診斷，候選去重、development rank 固定；final 測試由隔離 Evaluator 在凍結後讀取。研究作者不能自核准，獨立 reviewer 核准後才產 PublishedArtifact。

逐步失敗包括 checksum 不符、不足 split、未知單位、租約失效、取消競態、SSE 斷線及證據撤銷。各步預期錯誤與狀態見 AX-04／21／38；失敗後仍可讀已提交產物，但不假裝完成全部驗證。

## 後續領域案例的啟用條件

| 案例 | 階段與前置契約 | 驗收重點 |
|---|---|---|
| 衰減震盪 | M4 前可作 v1 複合顯式函數研究 | 混疊、窄域多解、樣本外預測，不能直接當物理機制 |
| Fibonacci／遞迴 | M5+，先定離散 DSL、索引與初值 | 少樣本多通式、整數精確性與缺失項 |
| AR(1)／變點 | 擴充模型契約與時間 split | 殘差、預測分布、變點不確定性；不強求顯式精確公式 |
| 行為／雙序列假相關 | M6，有群組／時滯／混雜與多重檢定協定 | 相關不等於因果，互斥須事件定義 |
| 多序列 | M7，條件關係及算力／樣本量驗收 | 高階交互與分群漂移，失敗可拒答 |

這些後續案例未具備完整 fixture 前保持 NOT_RUN／規格待補，不列入 MVP Gate 的必過清單。
