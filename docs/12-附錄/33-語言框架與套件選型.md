# 語言、框架與套件選型

> AXIOM | 規劃基線 v1.0 | 2026-10-19 | 文件：`12-附錄/33-語言框架與套件選型.md`

## 文件目的
整理前後端、數學、AI、運維的候選技術與取捨。

## 主技術棧

| 層級 | 首選 | 用途 |
|---|---|---|
| Backend | Python 3.12+、Django、DRF | API、治理、權限 |
| Frontend | Vue 3、TypeScript、Vite、Pinia、Vue Router | 研究工作台 |
| UI | KaTeX、MathLive、Plotly.js、Apache ECharts | 公式與科學視覺化 |
| Math | NumPy、SciPy、SymPy、mpmath、Polars | 數值、符號、精度 |
| Discovery | PySR、PySINDy、scikit-learn、statsmodels、Optuna | 公式與模型搜尋 |
| Storage | PostgreSQL、pgvector、Redis、MinIO | 結構、向量、佇列、物件 |
| Async | Celery、Redis、SSE | 背景工作與進度 |
| AI | ChatGPT API、Ollama、sentence-transformers | 規劃與檢索 |
| Proof | Lean 4（選配） | 形式化證明 |
| Ops | Docker Compose、Nginx、OpenTelemetry、Prometheus、Grafana、Sentry | 部署監控 |

## 可選替代

前端大數據可評估 deck.gl/WebGL；複雜工作流可評估 Temporal；GPU 訓練可使用 PyTorch/Transformers/PEFT；超大規模資料分析可評估 DuckDB/Dask/Ray；以上均應以瓶頸實測決策。

## 版本與授權

本文件列技術方向而非鎖定最新版號；實作前需建立 SBOM、檢查 Python/Node 相容、Julia/PySR 安裝成本、商業授權與依賴安全性。
