# 34｜術語表與證據等級

> AXIOM v2.2 設計規格｜文件 ID AX-34｜狀態：待實作、待驗收｜2026-10-19

## 文件定位與決策摘要

術語必須分辨 exact symbolic equivalence、approximate numerical agreement、structural identifiability、practical identifiability、predictive validity、causal identification；不得將「可信」作為無定義百分比。

## 章節專屬規格

### 核心術語

Formula/Equation：公式與方程；Model：包含結構與參數的模型；Hypothesis：可檢驗假說；Identifiability：可識別性；Provenance：來源鏈；Counterexample：反例；Structural Recovery：公式結構恢復；Out-of-Distribution：分布外；Calibration：校準。

### 證據等級

E0 未驗證猜想；E1 數值相符；E2 獨立樣本外驗證；E3 跨條件重複驗證；P0 無符號／形式化證明；P1 符號推導在假設下成立；P2 形式化證明核心接受。E 與 P 是不同軸，不能把 E3 當作 P2。

### 研究結論模板

必填：主張、資料來源、適用域、模型版本、候選替代、誤差、不確定性、反例、證據等級、可重現環境、待驗證事項。

## 證據代碼與雙軸相容規則

E/P 是實證與證明的兩個維度；v2 文字標籤是結果摘要，不能以單一總分取代雙軸資訊。

| 摘要代碼 | 最低證據要求 | 與 E/P 的關係 |
|---|---|---|
| LOCALLY_VALID | 已保存局部資料與容差內數值結果 | 可對應 E1；不得暗示樣本外有效 |
| SUPPORTED_EMPIRICAL | 至少獨立樣本外驗證與切分紀錄 | E2 起，跨條件重複驗證另記 E3 |
| VERIFIED_SYMBOLIC | 假設與符號推導可追溯 | P1；不代表受信任核心接受 |
| PROVEN_FORMAL | 受信任 checker 接受，保存前提、版本與輸出 | P2；不自動代表現實資料或因果成立 |
| AMBIGUOUS | 多個候選在現有資料下不可區分 | 可與已有 E 等級共存；不增加 P 等級 |
| FALSIFIED | 有可重現反例違反所述主張或適用域 | 撤銷該主張的可推薦資格，保留歷史 |
| INSUFFICIENT_EVIDENCE | 缺資料、驗證或 checker 未完成 | 不得從缺失結果推斷證明或反證 |

發布產物應分欄保存 empirical_level、proof_level、outcome_status 與適用假設。checker 超時屬證據不足，只有有效反例才能支持反證；新資料撤銷經驗模型，也不等於推翻在不同前提下成立的形式化命題。

## 共用規則

版本、錯誤、證據與審查規則見 [AX-48 共用契約與文件治理](<../00-總覽/48-共用契約與文件治理.md>)；本章的專屬限制及驗收條件仍須同時滿足。

## 欄位與摘要推導

empirical_level=E0/E1/E2/E3；proof_level=P0/P1/P2；outcome_status=SUPPORTED/AMBIGUOUS/INSUFFICIENT_EVIDENCE/FALSIFIED。摘要 label 由雙軸與狀態推導：SUPPORTED 且 P2→PROVEN_FORMAL，P1→VERIFIED_SYMBOLIC，否則 E2/E3→SUPPORTED_EMPIRICAL，E1→LOCALLY_VALID，E0→INSUFFICIENT_EVIDENCE；非 SUPPORTED 時以 outcome_status 為摘要。UNKNOWN 是 checker／等價判定狀態，不能拿來當 proof_level。推導標籤不刪掉其他軸的資訊，也不代表因果。
