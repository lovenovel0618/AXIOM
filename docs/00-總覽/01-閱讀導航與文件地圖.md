# 閱讀導航與文件地圖

> AXIOM | 規劃基線 v1.0 | 2026-10-19 | 文件：`00-總覽/01-閱讀導航與文件地圖.md`

## 文件目的
提供不同角色的閱讀路徑及文件之間的依賴關係。

## 建議閱讀順序

產品與 PM：00 → 01-需求 → 02-流程 → 08-UI → 11-交付；架構師：00 → 03-架構 → 04-數學 → 05-記憶 → 06-AI → 09-非功能；研發：03 → 07-資料與 API → 10-測試 → 11-交付。

## 文件規範

所有文件使用繁體中文 Markdown；Mermaid 為可編輯架構圖；需求編號 REQ-*、架構決策 ADR-*、測試編號 TEST-*、風險 RISK-*；每份文件標示基線日期。

## 變更控制

重大需求變更需評估對公式 DSL、證據模型、資料契約、驗證結果與 UI 的連動；架構決策需記錄背景、選項、取捨與回退條件。

## 驗收與交付準則
- 文件內所有決策均有負責角色、驗證方法及可追溯的需求編號。
- 未完成事項不得標示為已實作；未經獨立驗證的數學主張不得標示為已證明。
- 重大設計變更應同步更新索引、架構決策與相關測試計畫。
