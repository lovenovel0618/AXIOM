# 45｜非功能 SLO 與壓測方案

> AXIOM v2.9 設計規格｜文件 ID AX-45｜狀態：待實作、待驗收｜2026-10-20

## 目標與量測（均為待實測目標）

| 場景 | 初期目標 | 測量方法 | 失敗處理 |
|---|---|---|---|
| 資料集列表查詢 | p95 < 300 ms | 100 並發混合查詢 | 索引/快取/分頁 |
| 提交研究任務 | p95 < 1 s | API 負載測試 | 立即回 202 與 run_id |
| SSE 進度可見性 | 事件產生後 p95 < 2 s | 端到端事件追蹤 | 重連與 cursor 補發 |
| 10 萬點圖形互動 | 常見桌機可流暢縮放 | 指定硬體實測 FPS | LOD/抽樣 |
| 工作池恢復 | 崩潰後可重試/續跑 | Kill worker 演練 | checkpoint/冪等 |
| 單研究算力 | 不超出預算 | CPU/GPU 秒統計 | 終止並保存部分結果 |

## 壓測矩陣

資料規模 1k/100k/1m 行；公式 AST 深度 3/6/10；並行研究 1/5/20；CPU/GPU 工作池混合；資料庫查詢、MinIO 讀寫、SSE 事件、LLM timeout 分開量測。避免以一台開發機測試宣稱生產可承受容量。

## 性能分析

後端 profiling 區分資料解析、特徵提取、候選生成、參數最佳化、驗證與記憶檢索；前端記錄首次可互動、圖形更新、記憶體峰值。優化前後使用相同資料與版本對照。

## 工程落地細則與邊界驗收

### 補充規格 1

負載模型需包含 80% 輕查詢、15% 資料上傳、5% 研究提交的混合流量；分開測量互動延遲與背景任務吞吐量。

### 補充規格 2

工作池以不同公式 AST 深度、不同優化器與不同資料筆數壓測，記錄 p50/p95/p99、峰值記憶體與每成功任務成本。

### 補充規格 3

降級規則：ChatGPT API 不可用時可改 Ollama 或規則搜尋，但必須記錄策略變更並通知使用者；GPU 不可用時可排隊而非假稱完成。

### 補充規格 4

容量規劃先用一週代表性研究流量測量，再估算峰值與成長倍數；硬體規格由基準數據推導，避免先行固定過度配置。

## 量測口徑與通過條件

以下是預定測試協定，非現有容量實測。每次報告必填 CPU／RAM／GPU、作業系統、映像 digest、資料 hash、負載腳本版本與並發模型；macOS 與 WSL2 分開報告。

| 指標 | 起訖與統計 | 通過條件 |
|---|---|---|
| 列表延遲 | 客戶端送出請求至完整接收回應；成功請求 p95 | 指定負載下 p95 < 300 ms，另列錯誤率及逾時數 |
| 研究提交 | 客戶端送出至收到已持久化 run_id 的 202 | p95 < 1 s；重送不新增任務、不重複扣預算 |
| 進度延遲 | 事件產生至瀏覽器可見，需校正跨機時鐘 | p95 < 2 s；遺失／重複事件另列 |
| 圖形互動 | 操作至畫面更新，記錄 FPS 與長任務 | 流暢度數值門檻於 M0 確認；未定不得宣稱通過 |
| 工作池復原 | worker 中止至任務重領與最後產物恢復 | 無重複副作用、無遺失已提交證據；時間門檻待決 |
| 計算預算 | 實際用量對照分配量，含重試成本 | 達上限停止派新工作；量測取消延遲及尾端超支 |

### 執行程序

1. 以 1k 行／1 個研究確認腳本正確，再測 100k、1m 行與 5、20 並發；不直接執行所有維度的笛卡兒積。
2. 每個負載階段預熱 5 分鐘、量測 15 分鐘、冷卻至積壓恢復，至少 3 次獨立執行；若任務本身更長，延長觀測並記錄原因。
3. 80／15／5 為請求數占比，分別對應查詢／上傳／提交；SSE 長連線數另列。報告同時列背景任務吞吐、排隊時間及 API 延遲。
4. 注入 worker 中止、物件儲存斷線、Redis 重啟、外部模型逾時，檢查恢復後的 run、checkpoint、outbox 與事件 cursor。
5. 達到隔離／資料完整性違規立即停止；其他停止門檻依測試環境配額預先設定。故障情境與正常負載結果分開統計。

所有原始量測、分位數計算方式、錯誤分布與未通過項目均入報告；只展示成功請求延遲不得用來聲稱整體 SLO 已通過。

## SLO 完整性

p95 延遲不單獨作服務通過條件。測試報告另含 timeout／5xx 率、成功吞吐、queue wait 與積壓是否恢復；正式最大錯誤率、測量窗口及 error budget 由 D-06 在壓測前凍結。未定時只能報測量值，不可判 G7 PASS。100 並發指客戶端同時在途請求，不等同每秒 100 請求；報告請求到達模型與實測 RPS。網路、冷熱快取與上傳檔案大小均需固定記錄。
