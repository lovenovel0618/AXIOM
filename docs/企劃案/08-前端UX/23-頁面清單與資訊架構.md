# 23｜頁面清單與資訊架構

> AXIOM v2.9 設計規格｜文件 ID AX-23｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

頁面導覽：Dashboard→Datasets→Research Workspace→Candidates→Derivations→Evidence→Memory Graph→Benchmarks→Models→Settings。研究頁採固定研究 ID 與可分享的唯讀版本連結。

## 章節專屬規格

### 主要導航

總覽 Dashboard；專案 Projects；數據庫 Datasets；研究工作台 Research Studio；公式庫 Equation Library；片段庫 Fragment Library；理論演化 Theory Graph；證據中心 Evidence; 基準測試 Benchmarks；經驗記憶 Memory；AI 模型與訓練 Models；任務與資源 Jobs；系統管理 Settings。

### 研究工作台佈局

左側：資料／假說樹；中央：多圖層數據與公式曲線；右側：候選排名、參數、證據、警示；下方：任務時間軸、殘差、推導步驟與反例。面板可拖拉調整並保存工作區。

### 比較與決策

最多可同屏比較多個候選：公式 LaTeX、複雜度、樣本外誤差、外插風險、適用域、證明狀態；證據不足要顯著但不誤導地呈現。

### 路徑與承接狀態

1. `/datasets` 資料集清單：僅建立與導覽，列表以版本數、不可用版本數與總列數作為摘要。
2. `/datasets/:id` 資料集工作區：版本清單、上傳新版本、資料預覽、完整性檢核與版本比較；以 `version`、`base`、`target` 承接選定版本與比較對象，重新整理後可還原。
3. `/researches/:id` 研究工作台、`/discoveries` 發現中心、`/verification` 驗證中心：以 `run`、`pins`、`submission`、`submissions`、`focuscandidates`、`focussubmissions`、`ref` 承接候選與提交集合同步。
4. `/candidates/:id?run=<searchRunId>` 候選公式工作區：以來源 SEARCH 任務的候選分頁定位候選，呈現公式、參數、擬合與驗證；後端未提供單筆候選讀取，因此 `run` 為進入此頁的必要承接參數。
5. `/runs/:id` 任務詳情：SEARCH／FIT 任務會列出候選分支並以後端簽章游標分頁續接。
6. `/activity` 研究活動中心、`/pending` 待處理事件、`/resources` 資源監控：總覽模組三頁共用同一份「研究 → 版本 → 任務」與「資料集 → 版本／匯入任務」快照；後端沒有全域任務與即時硬體觀測端點，未讀取的頁面與未揭露的欄位一律標示「未取得」，不以推測補值。

### 狀態與空畫面

首次使用引導、匯入中、搜尋中、等待資源、無可辨識公式、結果歧義、模型失敗、API 不可用等狀態均有可行下一步。缺少結構預覽或無法解析時標示「未取得」，不以推測填補。
