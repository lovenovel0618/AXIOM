# 23｜頁面清單與資訊架構

> AXIOM v2.9 設計規格｜文件 ID AX-23｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

頁面導覽：Dashboard→Datasets→Research Workspace→Candidates→Derivations→Evidence→Memory Graph→Benchmarks→Models→Settings。研究頁採固定研究 ID 與可分享的唯讀版本連結。

## 章節專屬規格

### 主要導航

總覽 Dashboard；專案 Projects；數據庫 Datasets；研究工作台 Research Studio；公式庫 Equation Library；片段庫 Fragment Library；理論演化 Theory Graph；證據中心 Evidence; 基準測試 Benchmarks；經驗記憶 Memory；AI 模型與訓練 Models；任務與資源 Jobs；系統管理 Settings。

### 研究工作台佈局

左側：資料／假說樹；中央：多圖層數據與公式曲線；右側：候選排名、參數、證據、警示；下方：任務時間軸、殘差、推導步驟與反例。面板可拖拉調整並保存工作區。

### 比較與決策

最多可同屏比較多個候選：公式 LaTeX、複雜度、樣本外誤差、外插風險、適用域、證明狀態；證據不足要顯著但不誤導地呈現。

### 路徑與承接狀態

1. `/datasets` 資料集清單（`datasets`）、`/datasets/:id/upload` 資料上傳精靈（`data-upload`）、`/datasets/:id/preview` 資料預覽（`data-preview`）、`/datasets/:id/quality` 資料品質（`data-quality`）、`/datasets/:id/pipeline` 前處理管線（`data-pipeline`）、`/datasets/:id/explore` 多維探索（`data-explore`）、`/datasets/:id/diff` 資料版本比較（`data-diff`）：對應 SSOT SCREEN 11–17，七頁共用同一條頁籤導覽；清單頁不需資料集識別碼，其餘六頁以 `id` 為必要路徑參數，未選定資料集時頁籤僅顯示說明而不可點。資料上傳精靈以 `version` 承接選定版本；資料預覽以 `version`、`q` 承接選定版本與欄位搜尋；資料品質以 `version` 承接選定版本；前處理管線以 `node` 承接選定快照；多維探索以 `version`、`dimension` 承接選定版本與座標軸；資料版本比較以 `base`、`target` 承接比較對象，重新整理後可還原。後端只有資料集、資料集版本、上傳工作階段、結構預覽產物與匯入任務端點；存取權限與角色、資料集品質評分、資料來源型別、取樣列、量測單位與值域分布、缺失／異常／偏移／洩漏統計、轉換節點 DAG 與參數、投影座標、父版本血緣與回復流程等未揭露欄位一律標示「未取得」，不以推測補值；清單與工作區的統計範圍一律以實際讀取的頁面為限並標示截斷（版本數旁 `+`）。
2. `/researches` 研究清單（路由名 `research-list`）、`/researches/new` 新建研究（`research-create`）、`/researches/:id` 研究工作台（`research-workbench`）：三個路由共用同一條研究線查詢狀態（`version`、`node`、`focuscandidates`、`focussubmissions`、`flowkind`、`flowtone`、`flowq`）與 `ref` 回跳來源。研究清單的任務統計只涵蓋本頁實際讀取的版本並以版本 ID 明示範圍；後端沒有批次刪除或批次派送端點，批次動作只做彙總檢視與匯出目前視圖。新建研究精靈只送後端已定義的欄位，自治理策略（AUTO／DEEP）與外部傳輸審核因後端尚無欄位或端點而不提供。
3. `/discoveries` 候選公式庫（`discoveries`）、`/discoveries/compare` 公式比較（`discovery-compare`）、`/discoveries/latent` 隱藏變數探索（`discovery-latent`）、`/discoveries/derivation` 研究推演（`discovery-derivation`）：對應 SSOT SCREEN 18–21，四頁共用同一條頁籤導覽。候選公式庫與公式比較以 `candidate`、`run`、`pins`、`ref` 承接選定候選、來源 SEARCH 任務與並排比較集合；隱藏變數探索以 `version` 承接選定研究版本；研究推演以 `research`、`version`、`node` 承接研究、版本與選定節點。後端沒有全域候選端點，候選公式庫與公式比較的統計一律以實際讀取的頁面為範圍並在畫面明示；內在維度、樣本外誤差等未揭露欄位一律標示「未取得」。
4. `/verification` 驗證中心（`verification`）、`/verification/falsify` 反例搜尋（`verification-falsify`）、`/verification/inverse` 逆向推導（`verification-inverse`）、`/verification/proof` 形式化證明（`verification-proof`）、`/verification/graph` 證據關聯圖（`verification-graph`）：對應 SSOT SCREEN 22–26，五頁共用同一條頁籤導覽。驗證中心以 `submission`、`submissions`、`ref` 承接選定提交與集合焦點；反例搜尋以 `validation` 承接選定失效案例；逆向推導以 `run`、`candidate` 承接選定 SEARCH 任務與候選解；形式化證明以 `artifact` 承接選定證明產物；證據關聯圖以 `node` 承接選定節點。多面向證據矩陣以 `splitRole`（`FIT`／`DEVELOPMENT`／`FINAL_TEST`）為欄、缺欄一律「未取得」；反例空間、邊界條件、可識別性、逆問題求解器、命題與前提等後端未揭露欄位一律標示「未取得」；證據包或品質報告讀取失敗時保留空集合並標記不可讀。
5. `/memory` 知識庫（`memory`）、`/memory/experience` 研究經驗（`memory-experience`）、`/memory/failure` 失敗案例（`memory-failure`）、`/memory/recovery` 假設恢復（`memory-recovery`）、`/memory/evolution` 知識演化（`memory-evolution`）：對應 SSOT SCREEN 27–31，五頁共用同一條頁籤導覽。知識庫以 `version` 承接選定研究版本；研究經驗以 `run`、`verdict` 承接選定任務與結果篩選；失敗案例以 `case`、`category` 承接選定案例與類別篩選；假設恢復以 `version` 承接選定恢復項；知識演化以 `node` 承接選定演化節點。後端沒有專屬知識庫、經驗庫或知識圖譜端點，五頁一律只由研究、研究版本、任務、證據包、品質報告、最終評估與驗證結果推導；檢索標籤、策略與經驗摘要、根因與修復建議、恢復條件與預算、版本差異與撤回流程等未揭露欄位一律標示「未取得」，統計範圍一律以實際讀取的頁面為限。
6. `/candidates/:id?run=<searchRunId>` 候選公式工作區：以來源 SEARCH 任務的候選分頁定位候選，呈現公式、參數、擬合與驗證；後端未提供單筆候選讀取，因此 `run` 為進入此頁的必要承接參數。
7. `/runs/:id` 任務詳情：SEARCH／FIT 任務會列出候選分支並以後端簽章游標分頁續接。
8. `/activity` 研究活動中心、`/pending` 待處理事件、`/resources` 資源監控：總覽模組三頁共用同一份「研究 → 版本 → 任務」與「資料集 → 版本／匯入任務」快照；後端沒有全域任務與即時硬體觀測端點，未讀取的頁面與未揭露的欄位一律標示「未取得」，不以推測補值。
9. `/models` Ollama 模型管理（`model`）、`/models/routing` 模型路由（`model-routing`）、`/models/evaluation` 模型能力評估（`model-evaluation`）、`/models/storage` Token 與儲存（`model-storage`）：對應 SSOT SCREEN 32–35，四頁共用同一條頁籤導覽。模型管理以 `q`、`run` 承接任務關鍵字與選定任務；模型路由以 `class` 承接選定任務類別；模型能力評估以 `class` 承接選定任務類別；Token 與儲存以 `q`、`version` 承接版本關鍵字與選定研究版本。後端沒有模型登錄、模型路由、基準測試、Token 用量或儲存配額端點，四頁一律只由研究、研究版本、任務與其預算用量推導；模型名稱、上下文長度、模型版本與量化、候選模型、路由策略、任務到模型對應、基準分數、基準題庫與資料集、評分門檻與排名、事件保存與留存、壓縮政策、儲存配額等未揭露欄位一律標示「未取得」，統計範圍一律以實際讀取的頁面為限並標示截斷。

### 狀態與空畫面

首次使用引導、匯入中、搜尋中、等待資源、無可辨識公式、結果歧義、模型失敗、API 不可用等狀態均有可行下一步。缺少結構預覽或無法解析時標示「未取得」，不以推測填補。
