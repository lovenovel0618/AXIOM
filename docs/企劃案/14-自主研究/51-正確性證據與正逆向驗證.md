# 51｜正確性證據與正逆向驗證

> AXIOM v2.9 設計規格｜文件 ID AX-51｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

本章說明正確性不是單一百分比，以多軸證據、機率與校準契約、MAVE多路徑驗證及逆推工作，分別界定可回答與不能代替的範圍。

## 正確性不是單一百分比

REQ-013涵蓋M1～M3最小數值／實證／重現證據、M4經驗預判與反偏見、M5多路徑／逆向證明，以及M6～M7多維反演。EvidenceAssessment是對既有E/P、outcome及結論主張的補充，不能取代AX-34、升高原證據或自行解封final。

| 證據軸 | 可以回答 | 不能代替 |
|---|---|---|
| 數值 | 固定輸入、精度、誤差界是否可重現 | 公式描述真實世界 |
| 代數／推導 | 在明確域、假設及可信checker下是否成立 | 未驗初始模型的實證性 |
| 統計 | 在指定資料依賴／檢驗政策下效果與不確定性 | p值作假設為真的機率 |
| 預測 | 未見樣本的誤差、區間與校準 | 全域或永遠成立 |
| 結構 | 合成已知生成器下的AST／binding恢復 | 真實未知系統有可比較ground truth |
| 因果 | 識別假設、干預／設計與敏感度 | 相關、時滯或調整輸入值即可證因果 |
| 跨條件泛化 | 不同來源／環境／時間的重現 | 同一資料重跑多次 |
| 可重現性 | 輸入、環境、工具及容差的一致 | 重跑一致即可證真 |

每軸status用SUPPORTED／REFUTED／INSUFFICIENT／NOT_APPLICABLE／NOT_RUN，附evidence_artifact_ids及理由，不把未算指標填0或false。代數與推導可在math軸的分項報告呈現；數學證明只支持明確命題與公理，經驗理論仍是條件性支持。MVP未做的因果／形式化／機率估計清楚NOT_RUN，不因schema可表達而顯示已支援。

## 機率、區間與校準契約

ProbabilityStatement必須先定義event、method、hypothesis_space／prior／likelihood或calibration artifact、資料角色、適用域及估計值。BAYES_MODEL_POSTERIOR是指定候選集與先驗下的相對支持，不能顯示為「真實定律正確率」；模型集合外仍可能有更合理解釋。p值保留檢驗及多重比較計畫，不轉成1-p信心。PREDICTION_COVERAGE須註明名目coverage、校準樣本及條件；交換性不成立或時序依賴未處理就不引用一般conformal覆蓋保證。

機率模型／校準未知時value=null、reason非空；不得用LLM自評、模型投票比例、embedding距離或未校準歷史勝率補數。已有識別的輸出也需明列樣本數、分組／時間窗口及不確定性；未知真值的公式不能由經驗頻率推成真機率。先驗預判只改搜尋優先順序，另以no-memory及固定預算基準量測加速與負向遷移，不能直接晉升SUPPORTED。

## MAVE多路徑驗證計畫

| 方法家族 | 必填前提／產物 | 結果界線 |
|---|---|---|
| 代數、微分／積分 | 命題、域、初值、步驟與checker版本 | 符號timeout為UNKNOWN，不是反例 |
| 歸納、反證、逆向證明 | 基例／歸納假設、矛盾或子目標及已檢查引理 | 不是把A⇒B反過來當B⇒A |
| 形式化核心 | 公理／依賴、kernel版本及可重放proof | D-07及M5前停用；proof text不等於P2 |
| 數值、性質測試 | 輸入生成、seed、精度、誤差界及失敗點 | 未找到反例不等於全域證明 |
| 區間／嚴格誤差界 | outward rounding、區域分割、可重放證書 | 需受信任的界限證書，不能把一般浮點抽樣當嚴格界 |
| 統計／獨立資料 | sampling、split／seal、baseline、檢驗及停止政策 | 多重比較與依賴處理依固定版本；final一次 |
| 跨表徵／外部實驗 | 回原空間、初值、資訊損失、設計與來源 | 等價／近似／實證一致分開 |

每條路徑保存data_group、assumption_group、method_group、implementation_group、experiment_group。共享組不是數學上完全獨立；不能按三模型投票相乘likelihood或把同數據三種擬合算三份獨立證據。Proof graph與研究決策graph互相引用，證據隔離使依賴判斷待重審；替代不依賴路徑仍可獨立保留，不能機械刪除所有結論。

## 逆推的五種不同工作

| 工作 | 必要輸出 | 拒絕誤解 |
|---|---|---|
| 數學逆運算 | NONE／UNIQUE／MULTIPLE／UNKNOWN解集、域、條件及正代檢查 | 非單射不等於公式錯誤；$x^2=4$於實域解集為{-2,2} |
| 參數／結構反演 | 解族、objective、先驗／regularization、識別性、敏感度與區間 | 最佳點不是唯一真參數；正則化選解不是觀測證明 |
| 生成系統假說 | 相容ODE／遞迴／初值／替代機制 | 相容輸出不識別真實原因 |
| 目標導向證明 | 從目標列充分條件／子目標，逐條檢查引理與合成 | 搜尋不到proof不是命題為假 |
| 情境／反事實 | 模型介入假設、識別證據或明標SCENARIO_ONLY | 改輸入模擬不能冒稱因果反事實 |

InverseProblemResult固定question_kind、研究／candidate／input Artifact、域及參數約束、解集Artifact、solution_status、identifiability、forward_check_artifact_id與局限。NO_SOLUTION需方法可證不相容，solver timeout只給UNKNOWN；UNIDENTIFIABLE也可有多個數值解，不偽裝精確唯一值。$x\mapsto x^2$在$x\ge0$才可限制成非負平方根分支；沒有域限制不能任選正根。正逆回代只檢查內部一致性，不證生成機制；原反例／噪聲與假設仍保留。

## 證據充分性與停止

VerificationPlan在fit/development階段固定研究目的、必需證據軸與檢驗、baseline、域、誤差界、競爭模型集合、顯著性／校準政策、需要的獨立來源、資源限制及停止規則。MVP沿既有EvaluationPolicy，新增報告不能改其數值門檻。進階計畫要啟用新的機率、group／time或proof方法，需新policy版本及專屬契約，不修改正在執行的計畫。

證明任務可因可信proof完成；預測任務需預註冊樣本外誤差／coverage／穩定性；探索任務可合法輸出未解候選與區分性實驗建議。達到資源上限時停止不等於證據充分；輸出stop_reason、未滿足條件、競爭解釋及可推翻條件。重複看資料後才停止需預先設計sequential政策；MVP沒有可選停止保證，就不得任意追加測試直到p<0.05。D-03未定前正式數學外送仍BLOCKED。

## 充分性由可信判定產生，逆解由證據限制（v2.9）

evidence_sufficient是可信Evaluator依固定plan／policy、來源有效性、required_axes及全部criterion計算的唯讀投影，模型／客戶端不能自填true。true必須至少一軸SUPPORTED、unmet_criteria為空，所有required axes須符合計畫；NOT_RUN／INSUFFICIENT／REFUTED不可略過，NOT_APPLICABLE只有計畫事先允許且有理由才接受。評估計數、來源／plan hash、比較集與停止規則不相符就不足或拒絕；以evaluated_criteria_artifact_id保存每條criterion實際判斷，而非只有一個布林。schema可驗基本矛盾，跨物件與來源判定仍需可信服務。

InverseProblemResult的MULTIPLE／UNIDENTIFIABLE都必有solution_set與forward_check Artifact；UNIQUE需IDENTIFIED且有受限域內唯一性理由，不能只找到一個數值解就標唯一。NONE不能同時回非空解集，必有該域無解的可檢查證據；timeout保留UNKNOWN。COUNTERFACTUAL僅SCENARIO_ONLY或有識別證據的IDENTIFIED，後者必有causal_identification_artifact_id並在外送時另查policy／里程碑，不能靠enum繞過MVP禁止因果外送。純函數逆解不因回代通過就有因果識別。

| ID | 情境 | 預期 |
|---|---|---|
| AC-51-09 | 所有軸NOT_RUN或仍有unmet，卻自填充分true | shape／語意拒絕；不能以任意布林提升研究結論 |
| AC-51-10 | 非必要軸通過但required未過、計畫不允許N/A | 不充分；已固定criteria／hash可逐條核對 |
| AC-51-11 | 多解缺解集、NONE有解、純回代冒稱因果IDENTIFIED | 拒絕；多解保存可檢查集合，識別另需證據及外送政策 |
