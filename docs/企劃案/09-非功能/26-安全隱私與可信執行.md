# 26｜安全隱私與可信執行

> AXIOM v2.9 設計規格｜文件 ID AX-26｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

資料、上傳檔、公式、LLM 輸出、插件與 checkpoint 均不可信，須涵蓋惡意檔案、AST／prompt injection、資源耗盡、越權、盲測污染、秘密外洩及供應鏈；LLM 不得操作資料庫或宿主。

## 威脅與信任邊界

資料、上傳檔、公式、LLM 輸出、插件與 checkpoint 均不可信。需涵蓋惡意檔案、AST／prompt injection、資源耗盡、越權、盲測污染、秘密外洩及供應鏈。LLM 不得操作資料庫或宿主；插件只寫受限暫存。AST／求值在無特權 sandbox 執行，禁止 eval/exec、不可信 pickle 及宿主 Docker socket。

sandbox 使用非 root、唯讀根目錄、無網路、cap_drop=ALL、CPU/memory/pids/time 上限；輸入唯讀、輸出為獨立可寫 quota 目錄。可信 supervisor 驗證輸出大小、型別、hash 與 generation 後才可提交 DB。符號工具或 checker 不因是第三方套件就取得更多權限。

## 認證與身分

MVP 瀏覽器採同源服務端 session；cookie 為 HttpOnly、Secure、SameSite=Lax，所有變更須 CSRF header。session 於登出後失效，預設閒置 30 分鐘、最長 12 小時。這些為可調安全基線，不宣稱已測。服務帳號用短效 bearer token（預設 1 小時），綁 tenant、audience 與 scopes；只保存 token hash，可即時失效。瀏覽器不得把服務 token 放 localStorage。

系統不做角色與 ACL 分層：登入只提供 actor 身分（provenance／audit）與租戶分區，資源可見性由租戶分區與 access_class 分類政策決定，不因登入者身分不同而改變。配額與模型組態屬服務端設定，不是可逐次授予的身分權限。

每個資源含 tenant_id、owner 與 access_class；跨租戶或未存在的 UUID 一律 404，列表與 cursor 同樣過濾。MVP 不提供匿名分享連結。SSE 與下載 URL 必須持續受限，來源被刪除或隔離時禁止開新連線並中止既有串流；signed URL 有 15 分鐘上限，需要即刻收回時改由 proxy 串流，不發不可收回外鏈。

## 資料等級與外送政策

| 等級 | 本地 Ollama／規則 | 外部 LLM | 跨專案記憶／訓練 |
|---|---|---|---|
| PUBLIC | 可，仍需授權來源 | 僅 D-04 供應商政策通過後，提交最小摘要 | 分別明確授權 |
| INTERNAL | 同租戶本地處理 | 預設禁止；逐研究例外須登錄外送政策後才可 | 預設禁止 |
| RESTRICTED | 受控本地隔離，模型服務不得保留原資料 | 禁止，不能自動回退到雲端 | 禁止，另案政策才可變更 |
| UNKNOWN | 先隔離與分類，禁止模型路由 | 禁止 | 禁止 |

外送檢查在 Gateway 實際發送前執行，不能僅依 UI 勾選；包含 prompt、特徵、候選公式及錯誤回報。模型失效只能在同等或更嚴格政策的本地路由間回退；無合法路由就停用 AI、使用規則搜尋或回 FEATURE_DISABLED。匿名化名稱不保證資料已失去敏感性。記錄 policy_version、政策登錄版本、payload hash、目的地及 token 成本，日誌不存原資料或秘密。

## 刪除與衍生物傳播

以 lineage 計算影響範圍：原始檔→特徵→候選／驗證→記憶 embedding／快取→報告→訓練快照→模型版本。刪除先在權威 DB 同交易新增 tombstone、禁止推薦及寫 outbox，再異步清除索引／快取。所有推薦與報告下載都回查權威有效性，不能只信快取 TTL。

刪除工作狀態為 REQUESTED／BLOCKED／PROPAGATING／COMPLETED／FAILED。保存每個受影響物件、動作、重試及錯誤；部分清理失敗不得顯示 COMPLETED。歷史報告保留允許的非敏感內容並醒目顯示刪除／新證據；敏感內容刪除依政策不得只加標籤。已有外部匯出無法技術收回，記錄受影響匯出與允許的處理程序，不假稱已全部消除。

含已刪除資料的訓練快照移出可訓練清單；相關模型標 QUARANTINED 並停止服務，回退到無該 lineage 的有效模型，無有效模型則停用。重新訓練與重新驗收後才能解除，不宣稱刪一列就能從權重抹除資料。

備份保留受限且不供線上查詢；刪除 tombstone 清單獨立備份。還原後先重播刪除清單再對外服務；備份到期清除、法律保留例外與資料年限由 D-05 決定，未決時不接收受此政策約束的真實敏感資料。

## 內部紀錄與串流授權

RunRecord／AttemptRecord、BudgetAccount與UsageReport只供有任務scope的可信服務，不透過公開OpenAPI。Heartbeat／計量入口驗證服務身分與attempt所屬，遲到計量可接受但不授予產物提交權。兩種stream及所有cursor重播均重新檢查租戶分區與access_class；冪等回應重播也須重新檢查，不能以曾經成功當作永久讀權。

## 封存資料的逐資源讀取政策

Artifact.access_class必填PROJECT／SEALED_DETAIL，由可信服務依內容與lineage設定，客戶端不可自行降級。原始正式blind檔、final labels、逐點殘差、逐題分數、完整評估報告、final ValidationRun及其EvidenceBundle都受SEALED_DETAIL政策；一般自有資料原檔不因切分而自動變成正式未知blind，仍不得把final投影給Solver。

| 內容 | 一般身分（同租戶） | Evaluator服務 | Solver服務 |
|---|---|---|---|
| PROJECT | 依租戶分區與access_class政策 | 任務scope | 僅任務授權的fit/development投影及開發產物 |
| SEALED_DETAIL | 拒絕，不因自稱作者或服務帳號放行 | 需final:evaluate，綁tenant／submission／有效評估run | 拒絕 |

封存隔離由服務端access_class政策核發並審計，不接受請求body／header自稱。Evaluator憑證不能用於讀其他submission。任務scope不是整個研究的任意讀權，不能從已授權Candidate沿Artifact／DatasetVersion繞到final原檔。封存政策同時套用metadata、下載、ValidationRun、EvidenceBundle、清單、快照、事件與冪等回放；無權讀完整資源回404，不回部分偽造的ValidationRun。快照／列表過濾受限引用，事件按當前租戶與分類過濾且維持原stream sequence，客戶端容許過濾造成序號間隙。

原始SEALED_DETAIL不降級、不改內容或hash，也不因來源退役而自動改變分類。任意衍生Artifact仍繼承封存限制，不能只自填access_class降級。Schema／OpenAPI只記規則與形狀，分類政策必須在服務端逐次執行。

| ID | 情境 | 預期 |
|---|---|---|
| AC-26-05 | Solver服務讀final報告metadata、content、ValidationRun或bundle | 均404；列表／SSE不洩漏受限內容；fit／development投影仍可用 |
| AC-26-06 | 綁定submission的Evaluator讀final；改用其他submission參照 | 前者於該submission範圍可讀；跨submission拒絕，任務scope不得沿Candidate／Artifact繞到final原檔 |
| AC-26-07 | 一般身分讀自身專案開發結果；查詢含受限final引用的outcome_status／stop_reason | 可顯示允許的開發結果；受限欄位回null，不從null推斷零誤差或未執行 |

一般身分的Run仍可顯示控制狀態與自身允許的開發結果；若outcome_status或stop_reason透露受限final結論，對該身分回null，受限evidence／child引用不回傳。完整內部狀態不修改，投影及current_event_cursor在同一一致性讀點產生。ValidationFinished等含受限final引用的事件不投遞給Solver／一般身分；不能將隱藏指標寫入通用log、錯誤details、trace或通知。工作台不從被遮罩的null推斷零誤差或未執行。

## 永久責任歸屬

每個研究輸入、研究版本、執行根與人工候選／公式修改，建立時同交易產生私有ResourceProvenance，資源(type,id,tenant)唯一；creator_actor_id是不可變actor身分，responsible_human_ids包含直接作者、人工代送者及來源責任人的閉包，服務帳號必須繼承啟動人的責任集合。RunRecord.provenance_id指向它，子任務沿root及source_provenance_ids繼承，不能由worker自填乾淨身分。循環／缺失／跨租戶來源一律阻擋建立與執行，不能當成「無作者」。責任閉包永久保留，不因換owner、移轉研究或改用服務帳號而消失。

帳號刪除保留不可逆actor tombstone與必要責任關係，不能重用actor ID；具體保留期限／法規由D-05決定，未決定前不提供清除責任鏈的刪除操作。provenance是不可變歷史事實，不因帳號停用或資源異動而刪除。所有拒絕與存取決策均記持久audit，不能依賴24h冪等回應或7天SSE還原作者。

## 研究軌跡及AI紀錄的最小保存

「完整」只指與重建研究必要的外部產物；secret、禁止保留資料與供應商不可取得狀態不保存。trace／prompt／thinking若有／training log沿資料來源繼承分類、加密與retention，SEALED_DETAIL仍不能送Solver、embedding、經驗學習或訓練。StoragePolicy只由服務端設定允許root，模型與請求不能改路徑、保留或分類。原始討論內提到的全量永久保存不採納；D-05未定時僅處理合法公開／合成資料。
