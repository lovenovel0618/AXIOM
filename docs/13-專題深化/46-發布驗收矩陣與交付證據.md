## 記錄格式、簽核與回退

每筆結果包含 requirement_id、document_id、gate_id、test_id、release_version、environment_digest、dataset_hash、expected、actual、result、evidence_uri、executor、reviewer、executed_at。result 只允許 PASS／FAIL／BLOCKED／NOT_RUN；未跑不填 actual 或 PASS。Gate 可因不適用而註記範圍，但不得將未啟用的正式能力算作驗證成功。

所有 gate 通過且獨立覆核後才可發布；false proof、資料洩漏、越權與證據不可追溯不得豁免。非當期需求須正式修改範圍與追溯表，不以口頭說明跳過。D-03／D-06 未關閉，G2／G7 均保持 BLOCKED。

交付包含需求、ADR、schema/API、測試與效能報告、資安與授權清單、映像／模型／DSL 版本、部署 Runbook、相容 BackupSet、已知限制及簽核。回退先停寫／排空，再切相配映像、組態與 schema；不相容遷移從快照恢復並重播撤銷 ledger，完成 AX-27 驗收後開放。

| ID | 發布檢查 | 預期 |
|---|---|---|
| AC-46-01 | MVP 追溯清單少 REQ-003 或缺案例 | G1 BLOCKED |
| AC-46-02 | 有數學報告但 D-03 OPEN | G2 BLOCKED，不可預填通過 |
