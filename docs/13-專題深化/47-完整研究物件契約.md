# 47｜完整研究物件契約

> AXIOM v2.2 設計規格｜文件 ID AX-47｜狀態：待實作、待驗收｜2026-10-19

## 物件定義及所有權

結構契約見 [research-v1.schema.json](<../contracts/research-v1.schema.json>)，範例見 [research-v1.examples.json](<../contracts/research-v1.examples.json>)。各物件有明確 kind；共用欄位 id、tenant_id、schema_version="1.0"、created_at，使用 UUID／UTC RFC 3339。schema 只驗形狀；下列外鍵、資料可見性及狀態規則由服務與 DB 同時保護。

| 物件 kind | 專屬必要欄位 | 可變性／關係 |
|---|---|---|
| Artifact | owner_id、artifact_uri、sha256、size_bytes、media_type、status | Registry 內容不可覆寫，ACL 與有效性在讀取前檢查 |
| Dataset | name、owner_id | 名稱可改；資料內容放版本 |
| DatasetVersion | dataset_id、artifact_uri、sha256、format、row_count、status | 內容不可變；status 由審核／撤銷事件投影 |
| Research | name、owner_id | 容器可改名，不能改舊版本 |
| ResearchVersion | research_id、dataset_version_id、semantic_profile、split_policy、budget、purpose、status、revision | 語意／約束改動另建版本；狀態可變、revision 遞增 |
| Run | research_version_id（INGEST 可 null）、dataset_id（僅 INGEST）、type、status、revision、seed、environment_digest、active_attempt_id、lease_generation、current_event_cursor、budget_usage | type=INGEST/PROFILE/SEARCH/FIT/VALIDATE/REVOKE；FIT 與 VALIDATE 必填 equation_version_id，其他 type 不強制公式 |
| Attempt | run_id、generation、worker_id、lease_expires_at、checkpoint_id、status | checkpoint_id 可 null；generation 驗證見 AX-38 |
| EquationVersion | dsl、identity_hash | AST、domain、參數宣告在 dsl；不包含 FitRun 的估計值 |
| Candidate | search_run_id、equation_version_id、source、development_rank、validation_status | rank 未凍結時可 null；所有引用同租戶 |
| FitRun | run_id、equation_version_id、dataset_version_id、split_id、parameters、optimizer、precision | parameters 必須恰覆蓋 DSL parameters；記錄估計值字串 |
| ValidationRun | run_id、fit_run_id、split_id、metric_version、metrics、valid_coverage、empirical_level、proof_level、outcome_status、artifact_uri、sha256 | metrics 不可用缺值替代 0；split 與 FitRun 引用相容 |
| EvidenceBundle | research_version_id、validation_ids、proof_artifact_ids、status | 至少一個證據，尚無 proof 允許空 proof 陣列 |
| ProofArtifact | equation_version_id、theorem、assumptions、checker、checker_version、checker_status、artifact_uri、sha256 | checker=NONE 時不能標 CHECKED；不與數值驗證共用 status |
| ReviewDecision | research_version_id、evidence_bundle_id、reviewer_id、decision、comment、expected_revision | 不可變核准／拒絕，作者不得核准自己的產物 |
| PublishedArtifact | research_version_id、review_id、evidence_bundle_id、artifact_uri、sha256 | 發布凍結；撤銷以別表附加 |
| EvidenceRevocation | evidence_bundle_id、actor_id、reason、counterexample_artifact_id、status | 先阻擋推薦再異步清快取；反例檔可 null（例如發現資料污染） |

Run 是共用執行紀錄，SearchRun／FitRun／ValidationRun 是相應領域資料，不把所有欄位塞進同一張表。VALIDATE run 必須參照已有 EquationVersion；SEARCH 輸入不需要已發現公式。PROFILE 沒有候選，不能被相同 required list 拒絕。

## 語意物件

semantic_profile 必填 inputs、target、units_confirmed、time_ordered、measurement_resolution（可 null，須 reason）。inputs 每列 name/unit，target 同格式；名稱對應資料欄位，未知單位不能偽裝已確認。purpose 為 DESCRIPTION／PREDICTION／MECHANISM，MECHANISM 僅代表研究目的，不自動成為因果結果。

split_policy 必填 kind=IID_GROUPED／TIME_ORDERED／EXPLICIT、fit/development/final_test 的 row_ids、gap_rows、policy_version、sealed_final_test。各 row_ids 不重疊；預先沒有足夠 row 時阻擋執行。MVP API 只允許提交 row IDs 及切分政策，final_test label 由授權層封存，不送到 Solver。budget 必填 cpu_seconds、gpu_seconds、tokens、memory_bytes、wall_seconds、candidate_limit，全部非負，SEARCH 要求 CPU/wall/candidate_limit 大於 0；禁止將 tokens=0 解釋為無限。

## 不變條件

1. ResearchVersion 關聯 AVAILABLE DatasetVersion；下游全部引用固定版本，不能指向 latest。
2. 跨租戶外鍵一律拒絕。DB 使用 (tenant_id,id) 複合唯一與外鍵，API 先做可見性檢查，不能只靠難猜 UUID。
3. FitRun 的 split、資料、公式與 ValidationRun 完全可追溯；final_test 不可成為 optimizer 輸入。
4. EvidenceBundle 每項證據須屬同研究版本；核准時檢查 checksum、有效性、對應聲明的 E/P 級別及獨立 reviewer，不能只檢查非空 evidence_id。
5. 封存後改動產物內容或來源 hash 必須另建版本；撤銷不刪歷史。API 回應同時顯示最新有效性，不能讀到撤銷前快取仍顯有效。

## 驗收

| ID | 物件／操作 | 預期 |
|---|---|---|
| AC-47-01 | SEARCH run 無 equation_version_id；VALIDATE run 缺同欄 | 前者合法、後者 schema 不通過 |
| AC-47-02 | 新資料版本後讀舊 ValidationRun | dataset_version_id／checksum／指標不變 |
| AC-47-03 | 跨租戶 EvidenceBundle 引用 | DB 外鍵與服務都拒絕；無跨租戶洩漏 |
| AC-47-04 | bundle 有 id 但證據撤銷，或作者自行核准 | 不發布，回 INVALID_TRANSITION／FORBIDDEN |

## 欄位補充

EvidenceBundle 另必填 revision，狀態或撤銷更新時遞增，用於 revoke 的 If-Match。FIT／VALIDATE 是 coordinator 建立的內部 Run type，不接受使用者透過公開 SEARCH 提交端點任意指定；兩者必填 equation_version_id。ValidationRun.metrics 的 mae/rmse 無法計算時可 null；metric_reasons 是必填 object，正常為空，null 指標須給同名原因；不得填 0 或只丟掉失敗點。

Run 另必填 evidence_bundle_ids、child_run_ids；Candidate 另必填 fit_run_ids、validation_run_ids；尚未產生時為空陣列。DatasetVersion／ValidationRun／ProofArtifact／PublishedArtifact 另必填 artifact_id，引用同租戶 Artifact registry；其冗餘 URI／hash 只能由服務端由 registry 投影，必須完全一致，不能由客戶端指定不一致來源。
