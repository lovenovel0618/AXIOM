# AXIOM UI／UX 重製版：40 個功能頁

本次交付包含 **40 個獨立 HTML 原型、40 張 1440×900 PNG 截圖、40 份 Markdown 詳細規格**。所有頁面共用導覽與設計系統，但核心工作區按任務採用 20 種不同的專屬佈局類型。請開啟 `index.html`。

## 目錄
- `html/`：各頁獨立 HTML，可直接以瀏覽器開啟。
- `images/`：各頁獨立 PNG，與 HTML 一一對應。
- `docs/`：逐頁功能、欄位、互動、流程圖、時序圖、異常及驗收規格。
- `assets/`：共用 CSS、JS、頁面索引。

## 使用與限制
- 這是 **可瀏覽的視覺原型**，按鈕具示意對話框與基本互動，但尚未接入正式 API、Ollama 或研究引擎。
- Mermaid 原始碼在 Markdown 中，請用支援 Mermaid 的閱讀器查看圖形。
- 介面中的研究結果、模型指標與統計數值皆為示意，不代表 AXIOM 真實研究結論。
- 各頁時序圖提供設計層級的 API 互動，端點為示例，正式開發仍需以 OpenAPI/AsyncAPI 與事件 Schema 定稿。
- 請以頁面專屬 UI 工作區與 Markdown 驗收項目檢查設計，不應把「可點擊示意」誤認為正式可用功能。
