# 19｜策略學習微調與蒸餾

> AXIOM v2.1 整合基線｜文件 ID AX-19｜狀態：設計基線（未實作）｜2026-10-19

## 1. 文件定位與決策摘要

策略模型以特徵→搜尋方法排序為第一個訓練目標，標籤為同預算下的增益；先做離線 paired A/B，再做影子推論；微調只用已驗證且去重的樣本，定期測舊能力回歸。

**設計原則**：每個規範都要能轉換成可測試的行為、可追溯的證據或明確的工程決策；凡屬目標數字均非已實測結果。

## 2. 章節專屬規格

### 學習順序

第一層：檢索增強記憶；第二層：LightGBM 等策略選擇器；第三層：高品質資料驅動的本地 LLM 微調與蒸餾。模型推理不等於模型參數已訓練。

### 訓練資料

只納入具備完整上下文、演算法版本、預算、結果、驗證與負例的紀錄；記錄資料授權；按公式家族／來源切分；建立資料污染偵測。

### 升版閘門

封存基準集比較結構恢復、成本、拒答、最差群組表現；影子測試成功再上線；保留前版模型與快速回滾。

### 實驗設計

固定資料、種子、計算預算，分別測 no-memory、retrieval、retrieval+policy、fine-tuned；統計不確定性與負遷移比例必須報告。

## 3. 能力分解與詳細規格

### 3.1 AI 角色邊界

ChatGPT 用於複雜研究規劃與假說比較；Ollama 用於本地批次候選、分類與摘要；所有公式計算由 Python 可信數學引擎完成。

**強制規則／例外處理**：AI 回覆只作提案；需通過 schema 與數學檢查才能進入執行流程。

### 3.2 模型路由

根據資料敏感度、任務難度、延遲、成本、歷史品質、模型健康度決定本地或外部；失敗時退化到規則搜尋或其他已核准模型。

**強制規則／例外處理**：禁止未經授權將敏感數據傳送到外部 API。

### 3.3 策略學習

先訓練輕量策略排序器，特徵為資料指紋與預算，標籤為策略的樣本外效果與耗時；有證據後才進行本地 LLM 微調。

**強制規則／例外處理**：評估採相同資料、相同預算與盲測；防止相似生成公式跨訓練與測試切分。

### 3.4 負遷移與安全

記憶輔助搜尋與無記憶搜尋並行比較；偵測負遷移並降權；模型生成的 DSL、說明與工具呼叫均採白名單。

**強制規則／例外處理**：禁止 LLM 自行宣布已證明或跳過驗證。

## 4. 關鍵技術決策與邊界條件

1. 策略排序器訓練目標為固定預算下的候選收益，不以 LLM 自評作標籤。

2. 切分單位優先使用公式結構家族、資料來源與生成器版本，避免同源近重複洩漏。

3. 模型更新需通過離線 paired A/B、回歸基準、影子部署，並保留回滾版本。

4. 每次訓練保存資料清單雜湊、超參數、種子、程式環境、權重、評估報告與核准者。

## 6. 失敗情境與降級策略

| 失敗或風險 | 系統反應 | 留存證據 |
|---|---|---|
| 輸入不符合「策略學習微調與蒸餾」要求 | 拒絕執行並提供可修正的欄位錯誤 | 輸入版本、驗證規則、錯誤代碼 |
| 依賴服務中斷或超時 | 有限次重試；超出預算即終止並保存 checkpoint | 服務版本、耗時、重試紀錄 |
| 結果彼此衝突或證據不足 | 保留候選及歧義，不提升證據等級 | 候選集合、反例、驗證集 |
| 資源配額超出 | 中止重運算，保留已完成的可信部分結果 | CPU/GPU 秒、記憶體峰值、任務狀態 |

## 7. 可執行驗收案例

**AC-19-01 正常路徑**：給定完整合法的輸入、固定資料版本與計算預算，執行「策略學習微調與蒸餾」流程，必須產出可追溯的結果與完成狀態。

**AC-19-02 異常路徑**：故意提供缺欄、錯誤型別、超時或不合法狀態，必須得到明確診斷且不得產生已驗證的假結果。

**AC-19-03 重現性**：在固定輸入、版本、隨機種子與執行環境下重跑，輸出應符合預先定義的決定性或容差標準。

**AC-19-04 權限與審核**：未授權角色不得讀取或發布研究資料；審核者能查詢完整證據鏈。
