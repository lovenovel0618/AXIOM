# 19｜策略學習微調與蒸餾

> AXIOM v2.5 設計規格｜文件 ID AX-19｜狀態：待實作、待驗收｜2026-10-20

## 文件定位與決策摘要

策略模型以特徵→搜尋方法排序為第一個訓練目標，標籤為同預算下的增益；先做離線 paired A/B，再做影子推論；微調只用已驗證且去重的樣本，定期測舊能力回歸。

## 章節專屬規格

### 學習順序

第一層：檢索增強記憶；第二層：LightGBM 等策略選擇器；第三層：高品質資料驅動的本地 LLM 微調與蒸餾。模型推理不等於模型參數已訓練。

### 訓練資料

只納入具備完整上下文、演算法版本、預算、結果、驗證與負例的紀錄；記錄資料授權；按公式家族／來源切分；建立資料污染偵測。

### 升版閘門

封存基準集比較結構恢復、成本、拒答、最差群組表現；影子測試成功再上線；保留前版模型與快速回滾。

### 實驗設計

固定資料、種子、計算預算，分別測 no-memory、retrieval、retrieval+policy、fine-tuned；統計不確定性與負遷移比例必須報告。

## 關鍵技術決策與邊界條件

1. 策略排序器訓練目標為固定預算下的候選收益，不以 LLM 自評作標籤。

2. 切分單位優先使用公式結構家族、資料來源與生成器版本，避免同源近重複洩漏。

3. 模型更新需通過離線 paired A/B、回歸基準、影子部署，並保留回滾版本。

4. 每次訓練保存資料清單雜湊、超參數、種子、程式環境、權重、評估報告與核准者。
