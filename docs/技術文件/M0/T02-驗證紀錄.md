Python lock 固定 30 個相依套件；macOS 環境為 30 個，Linux image 另有內建 pip，報告為 31 個。相依套件包含 Django 5.2.18、DRF 3.18.3、Celery 5.6.3、redis-py 6.4.0、psycopg 3.3.6、NumPy 2.5.4、SciPy 1.18.1、SymPy 1.14.0、mpmath 1.3.0、Polars 1.44.2；精確間接依賴與平台條件以 [requirements.lock](<../../../tools/compatibility/requirements.lock>) 為準。

- [容器來源及 image digest](<t02-container-images.json>)：Python、PostgreSQL、Redis、Node 與本輪 probe image，全部為本機實測 arm64。
- [Node lock inventory](<t02-node-lock-inventory.json>)：Node／npm 版本、lock SHA-256、各平台 optional 依賴與 license metadata。
- [Python CycloneDX 1.6 SBOM](<t02-python-sbom.cdx.json>)：從 macOS 實際環境產生，30 components；CycloneDX Python 7.5.0 的 schema validation 通過。

CI 新增 compatibility-check，使用同一 Python hash lock／固定映像，以及 Node `.node-version`／npm lock。此處只記錄本機執行成功，未宣稱遠端 CI 已通過。
