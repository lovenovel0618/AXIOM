# T07｜時間與群組切分防線

2026-10-28；依 AX-09／AX-47，補完 M1 的語意確認。版本建立只驗 metadata 與固定列集合；PROFILE 在隔離程序驗真實時間／群組值後才可 READY。不能因建立版本成功就宣稱資料語意通過。

時間只接受來源欄中的有限數值或帶時區 ISO timestamp／ISO 日期，逐列嚴格遞增；重複、倒序或無效值都以相同遮罩阻擋品質。三區按來源列順序連續，兩個邊界各保留恰好 gap_rows，且 gap_rows 不小於 lookback_rows + horizon_rows。不另外掉列，時間與群組約束不能同時啟用。

群組必須整組分派；可信 worker 逐列以來源群組欄檢查跨區交叉。group_assignment_digest 定義為 canonical SHA-256 的 [[row_id, normalized_group, partition], ...]（來源列順序）。字串保留原內容，以 s: 為前綴；數字以 n:分子/分母 正規化。digest 不符或任一群組跨區即阻擋，PROJECT 報告不透露哪個 final 群組失敗。群組值不作特徵或標籤統計。

SEARCH／FIT 只取得 fit／development；final 封存的 CONTENT token 保存正規時間／群組識別，避免改時間或群組語意時丟失曝光身分。GROUPED_ROWS 的比較仍須 NONE；TIME_ORDERED 只能 NONE 或預註冊 BLOCK_BOOTSTRAP，尚無可信 block 比較時明確拒答而不套用 IID。

驗證涵蓋排序、重複、邊界 gap、群組交叉、digest、純 metadata 建立、隔離 PROFILE、搜尋不含 final labels 及既有 IID／EXPLICIT 回歸。這是單序列資料相依性保護，不包含 M6 的雙序列對齊或時滯搜尋。
