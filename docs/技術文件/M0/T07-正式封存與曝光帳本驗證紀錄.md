## 交付及界線

品質 PASS 後由專用 PROFILE child 固定 canonical final 觀測，於 Evaluator 私有 SQLite authority 保存 SealedTest／membership／exposure 與不可變 final 檔；公開 PostgreSQL 只存不含 tokens／labels 的 SealRegistration。自有資料沒有可信 Generator lineage，明記 OWN_DATA_SOLVER_ISOLATION、benchmark／case 為 null，不宣稱使用者未知真值。

曝光以 CONTENT／LINEAGE 兩種 tenant-scoped HMAC token 辨識；狀態機 AVAILABLE→RESERVED→CONSUMED、RESERVED→RETIRED，採先消耗後讀取、CONSUMED 不復活。journal authority 具 authority_epoch／sequence／previous_hash／payload HMAC／checkpoint，僅 append／read，經 Unix domain socket 交換；普通 web／Solver 不持 token。

## SELF_REVIEW

- 身分以租戶、source SHA、final rows hash 與 protocol hash 固定：重排列、換容器、換 split／dataset 重用同一封存 ID；protocol 改變或列子集不能洗白同批 final 觀測，一律 `TEST_ALREADY_CONSUMED`。兩條並行重疊登記恰一方成功。
- 先消耗後讀取：未 CONSUME 讀 final 回 `INVALID_TRANSITION` 且授權回呼未被呼叫；CONSUMED 對 RESERVE 為冪等、不復活；RETIRED 保留 tombstone。相同 submission＋snapshot 冪等，其他提交碰撞與缺欄一律拒絕。
- 密鑰缺失、journal 截短、authority 不可達全部 `EXPOSURE_RECOVERY_BLOCKED`，不以 SQLite 舊水位自稱恢復、不重新生成曝光密鑰。孤立 REGISTER intent 與刪除私有 DB 由 journal 重播到最新水位，且孤立登記不投影 READY。
- raw 升級命令只加 Evaluator 群組讀權（目錄 0750 且 setgid、物件 0440），保留寫入者所有權、永不 world-readable。sealed-data／sealed-keys 目錄 0700。
- RPC 邊界拒收相對路徑與過短／空 token；journal `network_mode: none`、不映射宿主埠、`group_add` 僅補 raw 群組，框架上限 262144 bytes、單連線單請求、token 以 `hmac.compare_digest` 比對。三自建映像基底改純 digest；T02 harness 改 trust 認證、不保存固定憑證。

## 升級、回退及後續
