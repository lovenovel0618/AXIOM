## SELF_REVIEW

- 精確欄名比對不 trim、不按位置推測；input／target 同欄或同 alias 拒絕。轉換比例、誤差界、尺度覆寫必須正數，practical_margin_ratio 在 (0,1]；小至 201 位小數仍可精確判正，不以 float 下溢判零。十進位各值有 256 字元上限，HTTP 維持 64 KiB。
- domain alias 必須相符，有理數須約分並禁止負零；反向／開端點空區間拒絕，閉單點域可保存，其觀測相容性留給 PROFILE。UUID 大小寫在資料綁定前正規化，避免合法 UUID 到 DB 才誤回 503。
- 三區非空、唯一、不交疊、不越界，當期無 gap 模式完整分配來源列，不默默刪列。各區保存排序原始 ID 及 canonical hash。IID 以已版本化 SHA-256 排序重算 seed，獨立固定預期列測試；不把使用者選定資料宣告為已證明 IID。
- READ／POST／冪等命中均查目前角色與 Dataset grant；READER 可讀舊草稿但不可重送寫入；撤權後清單與單筆一致遮罩。跨租戶、同租戶其他 ADMIN、停用 actor 都無法取得 owner 研究。
- 四執行緒相同 actor／key 只有一份草稿；插入故障回滾 provenance、audit 及冪等記錄。DB 複合 FK 防跨租戶，初始 DRAFT guard 拒絕假 READY／假結果／未登記封存引用；整列禁止 UPDATE／DELETE。
- 尚無事件串流；cursor 為 RESEARCH:{version}:0 的初始快照，沒有虛構事件。版本尚未執行，usage=0 只表示未開始，不是後續 PROFILE 免費或已建立完整額度帳本。
- 真實 Sonar 曾提示 PRNG 安全審查，已將切分改為版本化 SHA-256 排序並重跑到零診斷，沒有忽略提示。

## 遷移及後續

0005 新建 Research／ResearchVersion、分頁索引及同租戶唯一鍵；0006 加 native 複合 FK、provenance／DRAFT guard 與不可變 trigger，readiness 必須見到 0006。沒有修改既有 INGEST 資料或歷史執行紀錄。回退須先停寫與備份，reverse 移除研究表並非無損回退。

目前所有原始物件普通 API 仍拒絕讀取，sealed_final_test=true 為固定存取政策；SealedTest／ExposureLedger 尚未登記，不能聲稱正式未知資料評估。後續建立封存必須檢查跨版本／來源曝光，不能以新 ResearchVersion 重取資格。SOURCE_COLUMN 的存在與使用者單位確認不代表原值可轉數字、品質合格或已落在 domain。

下一步為可信 PROFILE／分區品質與 fit-only 結構評估、時間／群組檢查、研究預算帳本及已知 DSL 的授權投影／求值整合。工作台建立表單、refit、正式封存及搜尋仍待後續；M0／M1 與企劃驗收維持 NOT_RUN。測試環境只清理 axiom-t07c-check，未操作其他專案。
