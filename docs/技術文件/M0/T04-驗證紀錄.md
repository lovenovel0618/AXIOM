## 故障實測中的觀察與修正

第一次將所有服務放在 internal network 時，容器內健康檢查正常，宿主卻無法連入。已新增 web／frontend 專用 edge bridge，並實測宿主及前端代理；資料庫、Redis 與 worker 保持 private internal network。edge 仍可外連，不能當正式 Solver 出站沙箱。

Redis 中斷測試期間的 smoke 達到 30 秒上限而正確報逾時；它建立的 row 未丟失，在 broker／worker 恢復後完成一次。這是觀察逾時，不代表任務被取消。恢復後新 smoke 正常 PASS；未以增加等待時間隱藏故障。正式 Run 的取消、預算及有界失敗仍待後續實作。

前端模組載入另查出 Vite 非 root 使用者無法寫 node_modules 快取，已修正 Docker build 的檔案擁有者，並將實際模組 HTTP 請求補入 CI smoke，不能只靠首頁 HTML 判定 UI 可用。

Sonar 曾指出 CSRF middleware 缺少，已加入 CSRF、Security、X-Frame middleware，健康端點限定 GET／HEAD。沒有使用忽略規則、降低複雜度門檻或關閉型別診斷。
