# T07 研究預檢與已知公式整合設計

日期：2026-10-21；狀態：IMPLEMENTED（限本批本機預檢範圍）。承接研究 DRAFT；本批是有界資料品質與已知 DSL 的可信執行前置，不冒充完整 PROFILE Run。

## 需求與邊界

依 AX-09／10／28／47／49：固定來源與 split 後才讀值，不猜單位，不填補或刪列；先精確轉成 canonical SI，再檢查有限數及研究域。僅 fit 計算描述統計，development 僅評估使用者提供且已固定的公式，final 只做可信品質阻擋，不能評分、提供明細或回流搜尋。本批不支援時間／群組／refit，不自動宣稱週期、內在維度或物理宣告成立。

既有控制核心與 SQL guard 限 INGEST；ResearchBudgetAccount、SealedTest／ExposureLedger、研究事件及 PROFILE 狀態機均未完成。POST validate 仍 503，DRAFT 不改為 READY、不偽造 Run、quality_report_id 或 FIT_ONLY StructureAssessment。提供受信任本機 CLI research_inspect，actor UUID 不是遠端憑證；只處理當期有權使用的本機公開／合成資料。預檢與產品 AC／正式 blind 驗收分開。

## 執行與數值政策

重用三格式串流 parser，增加固定 observer；預設 INGEST 仍只產 metadata，不收集值。研究模式 JSON 十進位 token 以 Decimal 保留，仍先拒絕超出既有有限 float64 範圍的 JSON；CSV 數字語法顯式接受十進位及科學記號，字串不 trim，不接受 bool／null／日期／非有限值。Parquet float 保存原始二進位值，Decimal／整數精確；數字字串最多 256 字元，十進位 exponent 絕對值最多 1024，以免巨型有理數造成工作量失控。

比例及偏移用 Fraction 精確計算 canonical=source*scale+offset，再轉 float64（53 bits，nearest ties-to-even）。溢位、非零轉成零、精確值或 float64 捨入值落在固定 domain 外皆阻擋；例如有理上界 1/10 不偷放寬到略大的 binary64 0.1。這不是任意精度引擎。來源值不流出子程序；不在主程序執行 parser 或提供任意 worker 路徑。

研究預檢上限 4096 列（且受 ImportLimits 的更小值限制），只保存 fit/development 的 canonical scalar；final 品質逐列檢查後即丟棄值。三區完整分配、不交疊且 hash 正確，來源列數及欄名須與固定 metadata 相同。任一選定 input／target 無效，整份輸出只保留 quality=BLOCKED 與通用阻擋碼，fit 統計與模型評分均 null，不輸出分區、錯誤列、final 計數或原值。無關欄位的 scalar 內容不作數值要求，但仍套 parser 格式／容量限制。

品質通過時僅 fit 輸出 selected_count、unique_x、canonical target min/max/mean/IQR；統計以精確 Fraction，IQR 採 linear/type-7 量數。已知 DSL 在讀原值前完成 safe compiler 檢查，變數 alias／單位、輸出量綱及 domain 必須與研究完全相同，參數綁定完整且合法。模型只在 fit／development 求值，各區保存 selected/valid/failed、coverage、MAE／RMSE；任何失敗保留分母，指標 null，不以成功子集美化結果。精度、限制與參數 binding 隨執行記錄保存；沒有 final 評分或正確性宣告。

## 程序、授權與記錄

固定 research worker 沿用 Linux -I／-B、乾淨環境、私有目錄0700／input與request檔0400、address space 1GiB、CPU／wall deadline、stdout上限、killpg／wait。固定程式不是任意插件 sandbox，仍同UID且無網路／FS隔離。stdout只有經 schema／語意再檢查的遮罩結果，不含觀測投影。先於主程序以有界校驗讀 raw，因此父程序讀 I/O／總配額／crash清理仍為既有待辦。

執行前鎖 actor、owner 研究及 Dataset 寫授權，核對 User active、不可變 raw 物件版本／SHA、metadata、研究快照與 compiler。解析期間釋放 DB 鎖；提交時重新查同一 ACL／來源／環境，撤權／來源變更／環境變更不能保存結果。結果以 ResearchInspection 原生不可變表保存同租戶研究、actor、設定／來源／環境 hash、遮罩報告及實測 CPU／wall／process high-water。唯一鍵 (research_version,request_hash) 固定相同設定的重播，讀既有記錄也重新授權及驗 raw；失敗／未知用量不產成功記錄。暫不提供新 HTTP 路由或普通 Artifact，避免繞過 owner 私有研究與 Dataset ACL 交集。

記錄不是完整研究預算帳本：實測 CLI 成本不回填 ResearchVersion 的任務 usage，也不聲稱受研究累計額度保護。正式 PROFILE 要接研究額度／Run／事件／品質 Artifact／fit-only結構及曝光保護後才開啟。預檢可供 T07 已知公開公式示範，不關閉 M0／M1。
