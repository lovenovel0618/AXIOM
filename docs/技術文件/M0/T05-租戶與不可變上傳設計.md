# T05｜租戶、不可變物件與上傳授權

日期：2026-10-20；owner／SELF_REVIEW：project-owner。依 AX-09／21／26／43／48，先交設計，再實作與測試。

## 範圍

建立管理員預先配置的 Django session 帳號、固定租戶與 actor UUID、Dataset 與其 access_class、原始上傳 session、私有版本化本機 object adapter、不可變物件／provenance、冪等回應與 audit。提供 /auth/login、/auth/logout、/api/v2/datasets（GET／POST）、/api/v2/datasets/{id}/uploads，以及受 session／CSRF／短效簽章保護的 PUT proxy。資料集列表 cursor 按租戶／actor／排序簽章並重新過濾現行 access_class 政策。

MVP 每帳號固定一租戶，禁止請求自行選 tenant；一人可用多個測試帳號驗證兩租戶。建立與讀取資料集只需具備有效登入 session 的 actor，可存取的內容由資源的 access_class 決定，不因帳號身分自動擴大。管理命令可受控設定 access_class；沒有註冊、邀請、公開分享或 bearer 認證。

T05 僅完成傳輸、checksum 與版本固定。真正 parser／掃描／DatasetVersion／非 control Run 的 INGEST 由 T07 接入；complete 在當前授權與 request shape 檢查後回503 DEPENDENCY_UNAVAILABLE，不建立偽成功 Run 或版本。Artifact／封存讀取 API 尚未開放；檔案不由靜態伺服器提供。

## 認證與授權

Django auth／session／CSRF middleware；GET login 取得 CSRF 表單，POST 驗證帳密後輪替 session。登入失敗通用訊息，持久 login throttle 防止多 worker 繞過；本機預設每個 IP／帳號組合5分鐘5次失敗，計數 key 為 HMAC，不保存密碼。logout 只接受 POST＋CSRF。使用 axiom_session／axiom_csrf 避免共用 localhost 的其他專案 cookie 名稱碰撞；HttpOnly、SameSite=Lax session cookie；loopback HTTP 開發，正式 TLS／Secure cookie 由後續部署設定，不宣稱公網可用。

每次操作重新讀 enabled actor、tenant 與資源 access_class；idempotency replay／PUT 亦重新檢查，未知與不可見資源統一404。寫入按 actor→Dataset→Upload 鎖順序，access_class 變更亦遵守相同順序。跨租戶的 owner／upload／object／provenance 引用由 PostgreSQL 複合 FK／trigger 保護，不能只靠 ORM filter。

## 私有物件 adapter

本輪先實作 local-versioned-v1，介面輸入由 UUID tenant／upload／version 組成，filename 只作 metadata，永不當磁碟路徑。不採 MinIO 預設管理員憑證，也不宣稱已完成 S3 相容驗收；未來 provider 沿相同 immutable version／verify 契約替換。

web 專用 named volume，worker／frontend 不掛載。目錄0700、檔案0400；流式寫唯一暫存檔，實際 bytes／SHA256 符合後以同檔案系統 hard-link 原子建立且不可覆寫的版本，再提交 DB StoredObject。錯誤清理暫存，DB 失敗留下不可見 orphan，不能建立 AVAILABLE 版本。讀取用 O_NOFOLLOW／regular-file 檢查，核對固定版本、大小及完整 checksum，拒絕掉包、截斷、symlink 或缺檔，不追 latest。信任邊界為受控 web／storage 程序；本機 admin 可改磁碟，不能以 mode bit 宣稱抵抗 root。

UploadRecord 初始 OPEN，PUT 成功固定 object_version，仍保持 OPEN；T07 complete 才能原子標 COMPLETED 並建立唯一 INGEST。重複 PUT 相同內容可核對既有版本，內容不同回409 UPLOAD_OBJECT_CHANGED；逾時或 actor 已停用即使持有效簽章也拒絕。簽章有效上限15分鐘，綁 actor／tenant／upload／size／checksum；憑證放 UploadSession.required_headers 的 X-Upload-Token，URL 不含秘密，以免開發伺服器 access log 記錄 token。URL 只允許 PUT，不讀取或列物件。

傳輸上限50MiB，不代表解析／解壓安全；T07 仍須 ImportLimits 與隔離 parser。session 到期後不能重用簽章，新請求建立新 session。暫存／orphan 清理至少24小時寬限並排除 DB 引用；本輪不自動 GC 或刪除已登記來源，正式保留／敏感刪除仍受 D-05。

## 交易、冪等與稽核

必填 Idempotency-Key，scope=(actor,method,path,key)，保存 request canonical hash、當時 response 與24小時期限；actor row lock 序列化同 actor 並行請求。相同 key／payload 回既有結果，不重建 Dataset／Upload；不同 payload 回409。每次 replay 先驗目前 tenant 與 access_class，停用或刪除後不回舊內容或簽章。回應表示當時操作，已過期 Upload URL 不重新簽發；新簽章需新 key／session。

Dataset 與儲存來源建立時同交易保存不可變 ResourceProvenance；actor 身分及來源責任不因資源刪除或隔離而刪除。Audit 只記 actor／tenant、動作、結果與資源 UUID，不記密碼、token、原始內容或 exception。禁止更新／刪除來源事實及 immutable object metadata；不提供硬刪除 API。

## 驗證

真實 PostgreSQL＋本機 adapter，測兩租戶、同租戶不具讀取權、停用、CSRF、錯 token／token 換 actor／到期、tenant header 偽造、replay 後停用或刪除、cursor 移植、並行冪等、跨租戶 FK、provenance 不可改、filename traversal、checksum／size mismatch、版本掉包、symlink、重複 PUT 及磁碟失敗。加入 authenticated HTTP smoke，從 login→建 Dataset→建 Upload→PUT→驗固定版本；complete 明確503，不當成整合匯入。

通過 strict Pyright、Sonar、所有既有／新測試、文件檢查後提交 push，確認 CI。正式公網、S3／MinIO、研究資料隔離、掃描、INGEST 結果提交與完整產品 gate 不由本輪測試代替。

API 方法不符回405 METHOD_NOT_ALLOWED，未知路由404 NOT_FOUND，非預期服務錯誤500 INTERNAL_ERROR，皆使用相同 Error envelope 及不含例外內容的 request_id；已同步 AX-21、錯誤碼登錄與 OpenAPI。HTTP 伺服器本身的 TLS／協定錯誤不冒充研究 API 回應。

本輪人類測試帳號的 actor UUID 同時作責任人識別；不同登入帳號是否屬同一自然人尚未核驗，不能把測試帳號不同當成可靠的人類身分或責任歸屬。沒有開放對外交付 API，M3 實作前仍須完成可靠人類身分及政策驗證。
