## 查證與修正

本輪開始時 `docker compose ps` 確認 AXIOM 沒有運行中的服務；上一輪實際以 axiom-t07e-check 測試，結束後清除該可丟棄環境，並未保留可供使用者操作的開發服務。這與未執行測試不同，但原交接未交付可直接操作的服務。本輪啟動並保留預設 axiom-dev，不清除其容器或資料 volume。

根與 backend 原本已設定 Pyright strict，但 JsonObject=dict[str, Any] 讓 JSON 核心算術避開鍵與值型別檢查，不能以零診斷宣稱沒有型別問題。本輪新增 BudgetUsage／BudgetLimit／UsageReport TypedDict 與 Literal 欄位，ORM／JSON 邊界逐欄驗證後才進資源算術。Meter、預留、餘額、增量扣帳與終態提交已接入具體型別，不以 cast 把未知資料冒充用量。

補上帳本、PROFILE、匯入、研究配置、HTTP／access_class、事件／控制、原生 guard、parser 與數學核心的繁體中文用途及重要不變量說明。關鍵業務函式說明交易／鎖順序、重送、未知成本、遲到、遮罩與授權前提；成熟數學／parser 的詳細英文說明保留，另補中文流程。框架產生遷移不因中文化更動 SQL 行為。

## SELF_REVIEW 與殘餘事項

型別核心沒有 Any／JsonObject；全來源仍有 98 次 Any、386 次 JsonObject 名稱引用（含工具與測試），不是全庫零動態型別。既有 JSON／schema／框架相容邊界仍有顯式動態型別，以 tools/typing-boundaries.json 逐檔列管。其額度從前一提交建立，只能收斂；這是防止擴散的規範，不是全庫消除 Any 的證明。邊界的 ORM／函式庫容器適配 cast 不用來取代實際欄位驗證。

新算術不修改來源 account，先計完整新值再投影；bool、float、字串、負數、超安全整數、缺／多欄、候選數矛盾、倒退、總和溢位都有反例。真正超支仍保存，不裁切。原有完整帳本、取消／失聯、授權及 SQL 約束回歸保持通過。

Sonar 的新政策函式過度複雜已拆分為辨識名稱／別名及計數；例外測試的資料建構移出 assertRaises。沒有關閉 S3776／S5778 或其他規則。只改本專案服務；其他 Compose 專案保持原狀。正式封存／曝光、READY、SEARCH、工作台及產品 Gate 仍未完成。
