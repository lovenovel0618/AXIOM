## 交付與界線

新增 research_inspect 可信本機 CLI：對既有 owner 私有 DRAFT 重新查現行 Dataset 寫授權及來源，於 Linux 固定子程序解析三格式，檢查精確單位轉換、finite／overflow／underflow 及 domain。僅 fit 計算統計；提供固定合法 DSL 時，只將 fit／development 投入 evaluator，不讀 final 作評分。結果／設定／模型／參數、研究與來源／環境快照、執行用量保存於不可變 ResearchInspection。

任一分區 input／target 品質不合格都只回相同的 BLOCKED／DATA_QUALITY_BLOCKED，fit 統計與分數均 null；沒有 final 原值、列號、錯誤分區或計數。合法且不同的 final labels 不影響任何 fit 統計或開發分數。CLI 成本記錄不是研究預算帳本；正式 PROFILE 任務、封存／曝光與 fit-only 結構評估尚未接入，validate 仍 503，研究保持 DRAFT。

## SELF_REVIEW

- 精確 Fraction 轉換測 cm 與攝氏偏移；JSON numeric decimal token 不先丟失十進位精度，Parquet float 保留二進位來源。CSV 不默認 trim，bool／null／日期或不合法數字拒絕；無關 scalar 欄不強制數值化。Type-7 fit IQR 與 mean 用獨立固定預期值核對。
- 4096 列及既有 ImportLimits、1GiB AS、CPU／wall／stdout 限制沿固定 worker 生效；主程序只驗授權／來源／設定／結果，不解析觀測。既有 supervisor 的真正 CPU／AS／kill／wait 測試仍涵蓋共用執行器；研究 worker 另測真執行、請求與來源暫存清理、較小列上限。
- 任一區問題的遮罩結果完全相同；改動合法 final labels，整份結果相同。直接記錄 evaluator 收到的 x 僅為 fit／development，不含 final。沒有投影 Artifact 或通用 HTTP 下載繞過研究 owner。
- 模型 alias／單位／domain／參數在讀原值前檢查；域內 x/x 的 x=0 保留失敗分母，coverage=5/6，MAE／RMSE 為 null。另以固定參數常數模型核對非零 MAE=5／13 與獨立 RMSE sqrt(110/3)／sqrt(170)，避免只測零誤差。此為數值評分，不提升到物理真實或正式證明。
- 子程序回報嚴格限制鍵、數值字串、分母及 selected/valid/failed／coverage；額外 final_test、samples、原值或不一致計數拒絕。數值字串先檢查 Decimal exponent，再建 Fraction；1e±1000000000／NaN／Infinity／零分母均有反例，避免異常報告使父程序無界展開大數。
- 權限、User／Account 停用、同租戶其他 actor、執行中刪除或隔離、source 掉包及環境變更皆不能提交。既有快取也重查來源及 access_class。並行相同設定只一筆記錄，但可能重複做有界計算；不聲稱 exactly-once 執行或完整累計成本。
- SQL 同租戶 FK、研究 owner、來源及 metadata／設定快照 guard；記錄不能 UPDATE／DELETE 或偽造身分。ResearchVersion 保持不可變 DRAFT，沒有假品質 Artifact、Run／事件、帳本扣帳或 READY。
- Sonar 指出例外測試中的參數建構也可能拋錯，已移到 assertRaises 外；真分析重跑至零。測試的 domain alias 共用問題改成獨立 fixture，避免同時改研究與模型而失去反例辨識力。

## 遷移、成本與後續

catalog 0007 建 ResearchInspection 及 (research_version,request_hash) 唯一鍵；0008 加同租戶 FK、身分／快照 guard 及不可變 trigger，readiness 要求 0008。reverse 會移除新表，必須停寫／備份，不作無損回退承諾。只清理 axiom-t07d-check 測試資源，沒有操作其他專案。

measured_execution_usage 僅涵蓋當次子程序及父程序執行區間；CPU／wall 上取整、RSS 為 process high-water 保守和，不含前置 source I/O、compiler 或最後 DB 提交。並行執行／崩潰的完整成本帳本與總配額仍待後續；固定 parser 不是多租戶 FS／網路 sandbox，不接受正式 blind 或未核准敏感來源。
