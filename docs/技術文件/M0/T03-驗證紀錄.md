評分回歸包含缺預測、全失敗、空集合、非有限數、殘差溢位、可表達的大誤差、逐點容差、row ID 完整性及錯誤分母；沒有有效列時指標為 null。篡改資料／expected、數值假扮布林 mask、秘密欄位、未知公式字串、重疊／重排切分均拒絕。刻意把 MAE 實作改錯時，獨立 oracle 會使 CLI 失敗，不只檢查工具自行回報的 PASS。

輸出路徑回歸另驗證：無法寫入投影／報告時退出1、來源與輸出相同或 hardlink 別名時拒絕且不改動來源。Solver 投影重建新物件並重驗 split，不因呼叫者修改原 dict 就帶出 final 列。

題目級分區測試使用 synthetic 識別：相同家族同區合法，跨區家族／來源拒絕；family／source 各有命名空間。此驗證不會判定公式等價或自動識破偽造的來源 ID，產品可信來源及 lineage 仍待資料服務實作。

Sonar 初次指出例外測試內有多個可能拋錯的呼叫，已把測試資料建構移出 assertRaises 範圍；固定十進位政策以 Fraction 比對，實際除法則抽成 quotient helper，保留零點失敗而不簡化 x/x。最終重新分析沒有診斷。
